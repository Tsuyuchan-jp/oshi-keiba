# 投票とオッズ

## パリミュチュエル

オッズを運営が事前に「正しい値」として置かない。プールを的中者の投票比率で分ける。

Neko長明さん投稿の式（単勝のイメージ）:

`オッズ = (総投票額 TV × (1 − 控除率 D)) / (その馬への投票額 V)`

- D の目安: 20%（JRA 基準として言及された値）
- 少人数（目安 20 人）だと実投票だけではオッズが荒い・変動が極端、という問題が投稿の核心
- だから初期の V（シード）と、実投票の取り込み方（投稿では UV の重み、倍率、ブレ）が要る
- 投稿の「AI がステとスキルから強さを評価して V を置く」が、作者モデルの根拠

完璧な「もっともらしさ」は体裁の質の話。体裁の有無に必要なのは:

1. 締切後の正確な配当計算
2. 投票中にオッズらしき数値が見えること

素朴な表示で動かしてから縮小推定に差し替える、という順序は残してよい。

## 表示式

`Display_i(t) = Seed_i × w(t) + Real_i(t)`

- 投票が進むほど `w(t)` で Seed を薄くし、Real が効く、という意図
- `w(t)` の形、締切、配布量・賭け上限は未決
- 少人数でも Seed があるので、投票ゼロ付近で 0 除算や無限オッズになりにくい

## 賭式

- 複勝・連勝式はプールを賭式ごとに分ける必要があり後回し
- 計算レイヤは賭式を足せる形にしておく

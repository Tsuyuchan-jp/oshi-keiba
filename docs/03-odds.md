# 投票とオッズ（仮置き採用 2026-08-21）

質問ごとに採用をひっくり返すのはやめた。このファイルの「仮置き採用」節が正。計算の読み方は「内部計算（人間用）」を見る。下の対話ログは経緯。

## パリミュチュエル（前提）

本体はパリミュチュエル。Neko長明さん投稿:

`オッズ = (総投票額 TV × (1 − 控除率 D)) / (その馬への投票額 V)`

- D の目安: 20%
- 少人数（目安 20 人）だと実票だけでは板が荒い → Seed が要る
- Seed の中身は作者評価モデル（Strength の B）。Neko の 3 連単は Seed にしない

## 仮置き採用

### 画面の呼び方

- **投票中**: 参考オッズ（作者モデル＋これまでの実票の人気の目安。払う約束ではない）
- **締切後**: 確定配当（実票だけのパリミュチュエル。D=20%。この数字で払う）

同じ「オッズ」で払わない数字を出さない。参考と確定は閑散だと離れる。金銭ではないので完全一致は必須ではない。乖離しすぎは信頼を削るので、`w` と「実票に寄せる目安額」で後から触る。

### 表示と清算

`Display_i = Seed_i × w + Real_i` が参考オッズの中身。

- 清算・確定配当は **Real のみ**。Seed 込みで払わない（増刷しない）
- 買われていない頭が1着なら、その賭式は不成立・返還に近い（飛び入りで名簿外が1着、は別途要検討。再出走案あり）

### w

- 時間で薄く減らす＋実票量で減らす、の両輪
- **時間側**: 下限は厚め（閑散でも作者並びを残す）。時計だけでは 0 にしない
- **票量側**: 下限 0。人数ではなく実票量。想定の半分が乗ったらだいたい半分（初期錨）
- 合成は、時間だけでは 0 まで落とさず、票が十分なら 0 まで落とせる形（掛け算が意図と近い）
- **数値より、下限・曲線を管理者が UI で変えられること**が本体。初期値は上の錨。イベント後に触る
- Seed の山 **S** も管理者 UI で触れる（開始直後の作者並びの重さ）

### 実票に寄せる目安額（内部名 E）

- 週次配布 G とは **独立**。管理者 UI の項目
- 賭け上限ではない。実票がこの額に近づくと参考オッズを実票側へ寄せる
- 大きくすると作者並びが残りやすい。小さくすると実票・確定配当に早く寄る
- 配布額を変えても自動では動かない、と UI に注記する
- 管理者画面に計算の説明を載せる（内部計算枠）。人間用の控えはこのファイルの「内部計算（人間用）」

### ポイントと賭け方

- 仮想資産。週をまたいで貯め、来る週に厚く張れる
- 1頭へ所持全額を載せてよい
- 1人一票にはしない。複数頭・複数回・金額自由（残高内）
- ユーザー別残高があるので登録・認証が要る（ロードマップ⑥）
- 換金しない。1 ポイント＝ 1 円の**イメージ**（換金はしない）。景品は後で Neko長明さんと相談

### 口座（オッズの式に入れない）

毎週配る仮想ポイント【G】を、仮想のユーザー所持額【残高】へ足す。投票の刻み【単位】は、一度に賭けられる最小のポイント。

### 1　仮想の初期投票額

まだ誰も買っていなくても、当アプリが仮想の初期投票額【Seed】を乗せる。合計が【S】。各ウマ娘への分け方は、この出走メンバーの中での相対評価点【Strength】の比。小さな i は「そのウマ娘」。

```
Seed_i = S × Strength_i / Σ Strength
```

### 2　参考オッズを、仮想と実際のどちらに寄せるか（w）

参考オッズは、仮想の初期投票額【Seed】と、実際の投票額【Real】を混ぜて出す。【w】は、混ぜるときに仮想の初期投票額を何割残すか。1 に近いほど仮想が効く。0 なら実際の投票額だけになる。

寄せる原因は二つある。

一つめは時間【w時】。投票の開始から日時締切に向かって時間が進むと、仮想の初期投票額の効きを弱くする（w時 が下がる）。弱くはするが、時間だけが理由では 0 まで下げない。下限を残す。誰も賭けていなくても、開始時の付け方が参考オッズに少し残るようにするため。日時締切を置いていないときは、時間では減らさない。

二つめは実際の投票【w票】。実際の投票額の合計【TV】が、寄せ始める目安【E】に近づくと、仮想の効きを弱くする（w票 が下がる）。TV が E の半分なら、だいたい半分。E まで貯まると、こちらは 0 まで下げてよい。参考オッズは実際の投票額に寄る。

最後に掛けて【w】=【w時】×【w票】にする。時間だけでは 0 にならない（w時 に下限がある）。実際の投票が十分なら 0 にできる（w票 が 0）。

```
w時 = 下限 + (1 − 下限) × 残り^指数
w票 = max(0, 1 − TV / E)
w = w時 × w票
```

### 3　参考オッズ（投票中に出す。確定配当ではない）

そのウマ娘について、仮想の初期投票額【Seed_i】を【w】で薄め、実際の投票額【Real_i】と足す。この混ぜた値を【Display_i】と呼ぶ（参考オッズを出すために足した額。倍率そのものではない）。取消していないウマ娘の Display を足したものが【Σ Display】。これと控除【D】から参考オッズ（倍率）を出す。確定配当ではない。

```
Display_i = Seed_i × w + Real_i
参考オッズ_i = (Σ Display × (1 − D)) / Display_i
```

### 4　確定配当（締切後。仮想の初期投票額は計算に入れない）

確定配当は、実際の投票額だけで決める。仮想の初期投票額は計算に入れない。実際の投票額の合計【TV】から控除【D】を除いたものが払戻しの原資。それを、そのウマ娘の実際の投票額【Real_i】で割ると確定配当。口座に戻す額（払戻）は、賭けた投票額に確定配当を掛けて、小数を切り捨てる。

```
払戻しの原資 = TV × (1 − D)
確定配当_i = 払戻しの原資 / Real_i
払戻 = floor(実際の投票額 × 確定配当)
```

## 対話ログ（経緯。仮置き採用と矛盾したら採用側を正とする）

- 「荒れる」= 閑散で実票が1頭に偏り、その頭だけ超低・他が超高または計算不能。0件の横並びではない。0件で w が全頭共通なら比は Seed のまま
- 投票中に作者並びを残しても、確定配当が実票だけなら締切後は荒れた計算になる
- 時間下限が厚い → 2人目にも目安が残るが確定との乖離は大きい。下限が 0 近い → 逆。閑散をどれだけ見るかに正解はない。仮置きは時間下限厚め（普通の週を20人寄り）
- Neko 投稿の 4000 倍は、S と `w` と E に分けて参考側で受ける。ユーザーブレは後回し。払いには乗せない
- デモ初期値: G=1000、単位 100、E=S=20000。典型は G の約 7 割を本命。E は案 A（20G）
- 投票開始を部屋立て後に限る文は、スクショ先締めの週次に合わせて外した。開始時刻の前後は相談待ち

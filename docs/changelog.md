# 変更履歴

このファイルはアプリのリリースノートと版番号の運用ルールである。画面に表示する版番号の正本は `package.json`、表示位置とリリース手順は [docs/version.md](docs/version.md) を参照する。

## セマンティックバージョニング

`MAJOR.MINOR.PATCH` を採用する。まだ `0.x` 系のため、互換性の判断は慎重に行う。

- `MAJOR`: 運用・データ・利用者向けの使い方を大きく壊して変更し、安定版として公開するときに上げる
- `MINOR`: 互換性を保った利用者向け機能・画面・導線の追加で上げる
- `PATCH`: 互換性を保った不具合修正、小規模なUI改善、内部改善で上げる
- ドキュメントだけの修正は、原則として版を上げない。次のリリースの `Unreleased` に記録してよい

リリース前は `Unreleased` に追記する。リリース時は `Unreleased` の内容を新しい版の見出しへ移し、`package.json` と `package-lock.json` を同じ版に更新する。新しい版を上に書く。git タグは任意。

## 0.4.0 — 2026-09-02

### Added

- OCR後の新規出走登録に衣装選択、トレーナーアイコン、意気込みコメント入力を追加
- OCRでトレーナー名を出走者欄へ引き継ぎ、丸囲みの `i` 詳細ボタンを名前から除外
- OCR衣装名を、同一ウマ娘の衣装候補内で最大2〜3文字のファジーマッチに対応
- 登録済みウマ娘の詳細確認中でも、ヒーローの「出走登録」から新規登録画面へ戻る導線を追加
- 出走登録の完了通知を右上トースト化（再読み込み時の再表示を防止）
- 戦略例外の追加・削除・見送り・見送り解除をトースト通知に対応
- 登録済みウマ娘の詳細確認から、不採用スキルを戦略例外へ追加する導線を追加
- パドックの育成スクリーンショットをモーダル内で拡大して確認できるように追加

### Changed

- スマホの場内・入場・窓口ヘッダーを共通の配置基準へ統一。場内の書体・行間に合わせ、投票状態・現在時刻・締切時刻の位置と間隔を揃えた
- スマホの場内・窓口・入場を共通のグラス表示へ更新。背景画像を透かし、夜は明るい専用競馬場夜景を使用
- パドックのスクリーンショットモーダルを改善。拡大率は初期表示の2.2倍、閉じるボタンはスマホでも常時右上に表示
- スマホの場内・窓口ヘッダーを、状態表示と「場内／パドック／窓口」の等幅タブに分離
- 窓口ヘッダーにも現在時刻と締切時刻を表示し、状態案内を場内と統一

### Fixed

- `setup` 中の画像置換・出走削除・開催破棄などで不要になったR2スクショ／トレーナーアイコンを、Undoと両立させて削除するようにした。公開済み開催の画像と履歴は保持する。

- 投票開始前に、締切・開催設定・脚質別スタミナ8項目・スタミナ勝負の選択・出走登録一覧を確認するモーダルを追加。未設定や過去締切では、画面操作・直接API呼び出しのいずれでも開始できないようにした
- スタミナ勝負は「あり／なし」を明示選択するまで未選択として扱うように修正
- OCR読取後の不採用スキル候補表示で発生していた `attrEsc is not defined` を修正
- OCR衣装照合で、同じウマ娘の複数衣装を重複候補として扱い自動選択できなくなる問題を修正
- 新規出走登録後に通知トーストが表示されない問題を修正

## 流れ

1. `setup`: 本戦頭を登録。評価点（OCR または直置き）。賭式・S・E・締切
2. 投票開始 → `voting`。メンバーは `/bet` でその開催に参加してから買う（参加で G）
3. 日時または強制締切 → `closed`: 確定配当のみ。着順は出さない。賭式ごとに成立／特払い予定
4. 着順保存のあと公開 → `published`: 払戻。着順と自分の的中／特払い／取消
5. 「次の開催を開く」→ 新しい `setup`。前の開催は残る

文言: `setup` 出走登録中 / `voting` 投票中 / `closed` 投票締切（確定配当） / `published` 結果公開

## メンバー画面

- **場内**: 読む。単勝表が本体。本線は `voting` の「馬券を買う」（未ログインなら `/login` へ。参加前なら窓口で参加）。場内ヘッダーに入場・窓口のリンクは置かない
- **窓口**（旧・投票）: 書く。所持スペ。場内の「馬券を買う」から入る。画面内に場内へ戻るリンクはある
- `setup` 中も場内に入れてよい。投票開始まで待つ旨。参加ボタンは投票中だけ
- メンバー向けはすべて「オッズ」。評価点・Seed・控除の記号は出さない。「換金しない」も出さない
- 使い方・ログアウト・管理者は、枠内の「⋯」（ほか）。PCは枠外右下にも重ねてよい。スマホは⋯だけ。入場は未ログインなのでログアウトは出さない。場内・窓口・入場のモックで揃える（本番未適用）

紙面: 本番はまだ和紙・明朝（`src/lib/ui.ts`）。場内の正は [layout-venue.html](mocks/venue-board/layout-venue.html)（投票中・締切・結果公開まで採用。⋯あり）。窓口は [quiet.html](mocks/bet-window/quiet.html)、入場は [gate](mocks/gate/index.html)。枠番色・行タップで買う、はやらない。本番の買いUIはまだセレクト。

場内盤の面（採用。本番は締切後も和紙の別カードのまま）:

- `voting`: 変動あり。橙の「馬券を買う」。着列なし
- `closed`: 確定配当。着順は出さない。買うは出さない。賭式の成立／特払い予定
- `published`: 最初は払戻盤（左）と縦長の確定盤（右。ローマ数字・大きな通し番号・右は1着〜5着。タイムは雰囲気用）。スワイプ／タップ／「全頭」で全頭表＋自分の馬券。買うは出さない。着差は出さない（入力しない）

単勝表の列は **番号・ウマ娘名・出走者・脚質・オッズ**（公開後は右に着）。小数1桁。番号は名簿の通し（ゲームの枠番ではない）。取消すると詰まる。開始後の取消は避ける。スクショはメンバーに出さない。

### 投票ページ

- 未参加の投票中は、買うUIを出さず「（開催名）に参加する」だけ。参加後は今どおり買う
- 賭式タブ。初期は単勝。無効な賭式は出さない。1行横スクロール、アクティブは下線

## 入場

`/login` 1枚・2ボタン。個人パスワードなし。なりすまし耐性は捨てる。見出しは入場。URL はそのまま。

- 初めて: 未登録なら口座作成。同名ありは拒否。G は入らない
- 再入場: 既存なら入場。名前なしは拒否
- 表示名: 空白だけ不可。絵文字可
- Cookie があれば再入力不要。投票期間外の入場は可
- 投票中に `/bet` で「（開催名）に参加する」。初めての参加でその開催の G が1回入る。来ない人には配らない

## 賭式と払い

各賭式は別プール。当選キーは常に1つ。複勝・ワイドは当たりが複数なので後回し。

**①**: 確定は実票だけの山分け。Seed は投票中の参考にだけ混ぜる。

**特払い B**: 当たりの組み合わせに実票ゼロのとき、その賭式に賭けた人全員へ控除後を戻す（100 → 80、端数切り捨て）。全額返還ではない。

出走取消は別。そのウマ娘を含む票は全額戻す。

## 管理

- レースイベント設定はアコーディオン。開始後は通常いじらない。S・E・w時・D・締切・タイトルは投票中も保存できる（Undo の1手）
- 賭式のオンオフは setup だけ
- 出走の登録名はウマ娘名と出走者を分ける（OCR はウマ娘名へ。詳細は [ocr.md](ocr.md)）
- 管理は 6 タブ（進行・出走登録・出走・台帳・オッズ・開催設定）。OCR は `/admin/register`。読取成功の画像が登録時に R2 へ。出走タブでスクショ確認。[ocr.md](ocr.md)
- 管理の見た目はダッシュ（IBM Plex CDN）。逃げは開閉レール。着順は案3。内部計算はオッズのモーダル。掛かりスタミナ2欄は未実装。電光は移さない
- **本番デプロイ**は `ocr.md` の「デプロイ（忘れない）」。R2 作成と D1 `--remote` を `deploy` の前にやる
- デモ初期化: 本番では出さない。ローカルは `ALLOW_DEMO_RESET=1`。表示名は残す。開催・票を消し残高は 0。G は配らない
- 投票開始後は Undo・メンバー削除を普段押さない
- 「次の開催を開く」は結果公開のあと。誤って開いた setup は「この開催を破棄」（管理者パス＋確認）
- 投票開始が早いときは「投票を取り消して登録に戻す」（票は全額戻し、その開催の G も戻す。管理者パス＋確認）
- 出走クリア・開催破棄・投票の登録戻し・操作を戻すは、いずれもモーダルで管理者パスと確認ダイアログ
- 締切日時は開始ボタンと別フォーム。保存してから開始する（過去日時だと開始直後に自動締切）

# 自分の馬券

メンバーが、自分で購入した買い目と結果を紙の馬券に近い見た目で確認するページ。URL は `/tickets`。ログイン中のメンバー本人の馬券だけを表示する。管理者も確認専用で開ける（管理者自身の投票だけを表示し、購入操作はできない）。

## 表示単位

- 同じ賭式・同じ買い目へ複数回投票した場合は1枚へまとめ、購入額と購入回数を合算する。賭式ごとに見出しを分け、各賭式内は新しく買った順に並べる
- 「やりなおし」で取り消した投票は表示しない
- 出走取消で返還された投票は残し、「取消」スタンプと返還額を表示する
- 馬券には開催名、賭式、馬番の組み合わせ、ウマ娘名、購入額、購入回数、直近の購入時刻を表示する
- QRコードなど、実際には機能しない要素は置かない

## 開催状態ごとの表示

- `setup` / `voting`: 購入内容と「結果を待っています」
- `closed`: 購入内容と確定配当。着順と的中・外れはまだ表示しない
- `published`: 的中は大きな赤い「的中」スタンプと払戻額、外れは彩度を落として「はずれ」、出走取消は「取消」。第3回以降は特払いを出さない。第2回までに付いた特払いは「特払」のまま残す

## 導線

- 場内・窓口・パドックの3点リーダメニューに「馬券」を置く。上部の主要ナビ3枠は増やさない
- 窓口のスクロール領域下部には、馬券枚数・購入合計と「馬券を見る」リンクを表示する
- 結果公開後の場内では、結果の盤に大きな馬券結果案内を上部に、全頭表示に同じ案内を一覧の下部に置く。いずれも専用ページへの導線にする
- 場内には馬券明細の小さな一覧を重ねて表示せず、確認は専用ページに集約する

## 表示の揃え方

- スマホでは他のメンバー向けページと同じグラスモーフィズム背景を使い、背景画像は画面に固定して本文だけをスクロールする。ヘッダーは固定しない
- PCでは、賭式ごとの馬券カードを同じ横幅で並べる。1枚だけの賭式でもカードを全幅には伸ばさない

## 実装状態

DB追加は行わず、既存の `bets` と `payouts` から毎回表示を組み立てる。PC・Pixel 7相当のブラウザ自動テストは通過。

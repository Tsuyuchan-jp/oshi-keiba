# パドック

**実装クローズ（実機確認OK。2026-09-09）。** メンバー画面 `/paddock` で、脚質ごとに出走ウマ娘を並べ、選択した1頭の詳細を表示する。選択したウマ娘は窓口の投票候補へ引き継げる。

## 開催設定

- 管理画面の「イベント概要」に、開催ごとの「意気込みコメント」オン／オフを置く。
- 初期値は **オフ**。出走登録中（`setup`）だけ切り替えられる。
- オフの開催では、出走登録・編集画面に意気込み入力欄を出さず、パドック詳細にもコメント本文を出さない。
- オフにしても、すでに保存済みの `horses.paddock_comment` は削除しない。将来オンに戻せば再表示・編集できる。
- 設定値は `events.paddock_comments_enabled`（0 / 1）。`0019_event_paddock_comments.sql` で追加した。Undoの復元対象にも含める。

## 詳細カード

上から、脚質・ウマ番、ウマ娘プロフィール、トレーナー情報帯、（オン時のみ）意気込み、スキルパワー、基礎能力、投票候補への導線を表示する。

- プロフィール: petit、ウマ娘名、衣装名、オッズ。衣装名は `dress_id` から衣装カタログを引く。衣装未選択・旧データなど、解決できないときは衣装名の行を出さない。
- トレーナー情報帯: トレーナーアイコンを常に左に表示し、右に `TRAINER` とトレーナー名を並べる。アイコン未登録時はプレースホルダを表示する。
- 意気込み: 開催設定がオンのときだけ、トレーナー情報帯の下に吹き出しを置く。未登録時は「意気込みコメントは未登録です」と表示する。
- オッズ: ウマ娘名まわりで読み取りやすい大きさにし、PC 20px、モバイル 23px を基準にする。

パドックの詳細カードは、コメントがオフでもトレーナー情報帯を残す。情報を削った空白ではなく、プロフィールから能力情報へ自然につながる構成を正とする。

## 表示しないもの

- 評価点、Seed、控除、各投票者の投票内容
- 枠番色、人気順、過去走など、保存・算出していない情報

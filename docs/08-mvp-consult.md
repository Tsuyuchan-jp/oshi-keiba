# MVP 手土産と相談の切り方（仮置き採用 2026-08-21）

要件を一人で決めきってから出すより、**動く MVP を手土産に週次フローと未決を相談する**。催し全体の大確認はしない。完成物ベースの提示、という既存方針の具体化。

技術の仮置き（参考オッズ、Strength B、馬券締切の上限など）は相談で全部開き直さない。動く板を見せたうえで、Neko長明さんの運用に直撃する箇所だけ聞く。

## 仮で決めて作る（手土産の中身）

ここが無いと「馬券アプリ」として見せられない。数値や文言は仮でよい。画面に「仮」と出してよい。

| 塊 | 仮で固定して実装するもの | 相談しない理由 |
|---|---|---|
| 儀式を壊さない | note を置き換えない。着順は手動。ツールはネタバレしない公開スイッチ | 既存の中心体験。こちらから変えない |
| 呼び方 | 投票中は参考オッズ、締切後は確定配当。Seed 込みでは払わない。D=20% | 作者判断で「ずらしたオッズ」は却下済み。説明用の芯 |
| 馬券締切の上限 | ゲーム内で着順が見える前。日時＋強制ボタン | 結果後投票を防ぐ。ゲーム仕様から来る |
| 週次の骨格 | スクショ締切 → アプリで名簿と Seed → 投票 → 部屋 → note | 相談で開始時刻は動かす。骨格は動くものが要る |
| 飛び入り | ルール上禁止として実装（名簿外は乗れない前提の UI） | 明言する。例外処理は相談 |
| 取消 | 事前あり・ゲーム内なしは、その頭の票を返還 | 実競馬と同じで説明しやすい |
| 賭式 | 単勝だけが動く | 3 連単儀式と競合しない最小 |
| ポイント | 残高・蓄積・1頭全額・複数頭可。配布枚数は仮の数字 | 経済の中身は相談。口座の形は見せる |
| Seed | 作者モデル B。手動入力または粗い自動でも、初期の参考オッズが出る | V は製作者の仕事。Neko の 3 連単は入力にしない |
| 清算の最小 | 着順を入れて確定配当で払戻する画面。公開前は着順を出さない | 手土産に「最後まで回る」が要る |

実装してよいが、MVP で完璧にしなくてよいもの: U-tools 全自動、温存ツール連携、管理者向けの長い説明文、認証の本実装（閉じた試作で足りる）、③のコメントや誰が賭けたか。

## 手土産を持って相談する

Neko長明さんの週の回し方・負担・メンバーへの言い方に直撃する。**正解を先に決めない。** 仮の並びと仮の数字で動くものを見せてから聞く。

| 聞くこと | なぜ先に決めきらないか | 手土産で見せる仮 |
|---|---|---|
| 馬券投票の開始は部屋立ての前か後か | 土曜の部屋と、板が開いている時間の本体。運用の核 | スクショ後に投票開始、部屋はその後、の並び |
| 毎週の配布枚数・最低単位 | メンバーの「いくら持つか」。作者だけでは inflating する | 仮の配布で何週か回せる画面 |
| 景品・控除 20% の行き先 | 換金・現物は禁止済み。中身は主催側 | ポイントが減る／貯まる様子だけ |
| 誰がどのボタンを押すか（馬券締切・着順公開） | 作者はプロデューサーではない。押し忘れは事故 | 日時＋ボタン付きの管理者画面 |
| 36 コース内が Seed 本線、という使用条件 | コース選定に効く。伝えるのは完成後より、動く板を見たあとが早い | 36 内のサンプル出走で Seed が出る |
| 飛び入りが起きたら再出走するか | 禁止は仮置き。起きた週の主催判断 | 名簿外はアプリに出ない、と説明できる状態 |
| メンバーシップ内での扱い（必須か任意か、告知の文） | コミュニティの温度。アイビーさんへの一言のタイミングも含む | 閉じた URL で動く試作 |
| 単勝以外を足すか | 儀式が 3 連単でも、MVP は単勝で足りるかもしれない | 単勝だけが買える |

一度に全部聞かない。手土産のデモのあと、上から順で足りる。

## 作者が抱えたままにする（相談しない）

Neko長明さんに設計してもらわない。あとから比率や錨を作者が直す。

- Strength 混ぜ B、3:1 の仮、温存の錨と 16〜40% の中間
- 根性の追い比べをコース特性にするか
- 36 外の近傍の定義（例外週の作者作業）
- `w` と目安額 E の曲線の初期値（管理者 UI で触れること自体は作る）
- Seed の山 S と E の関係（実装穴。作者側で仮を置いて動かす）
- 技術スタック、認証の詳細
- シミュ・リプレイ・ブックメーカー・Seed に 3 連単、は却下のまま聞かない

## 手土産 MVP の合格線

身内または作者一人で、次が最後まで回れば提出してよい。

1. スクショ相当のデータを管理者が入れる（手入力で可）
2. 参考オッズが出る
3. 複数アカウント相当で賭けられる（ポイントは仮配布）
4. 日時またはボタンで馬券が締まり、確定配当に切り替わる
5. 着順を入れて払戻できる。公開スイッチより前に着順が見えない
6. 取消1頭の返還がデモできる

これより先の磨き（自動バ身、美しい管理者文、本認証、社会的要素）は相談のあとでよい。

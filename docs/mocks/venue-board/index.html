1. レイアウト比較（サイト感 vs 全画面アプリ）

「ブラウザ内全画面」とスマホ対応は矛盾しません。スマホアプリも全画面です。難しいのは横に余白のあるサイト型のまま拡大することではなく、 画面全体をシェルにして、中だけスクロールすることに寄せることです。

現状に近い

サイト型

全幅ヘッダー＋中央 max-width のメイン。左右に余白ができ、「ページを読んでいる」感じが出やすい。

開く
スマホで好評

アプリシェル型

100dvh でヘッダー固定、盤面が残り高さを埋める。表だけ縦スクロール。狭い幅でも「端末の中のアプリ」に見える。広い幅では盤が横に伸びやすい。

開く
PC向けの提案

場の中の掲示板

狭い幅は下端に芝が見える余白。広い幅は横長ビジョン。日中／夕方／ナイターは実時間（JST）か画面左下で切替。

開く
  • layout-venue.html はウィンドウ幅を動かして見てください。720px 前後で切り替わります。
  • 背景は写真ではなく CSS（夜空・照明・芝・レール）。本番で写真を使うなら暗く・低コントラストに抑える。
  • safe-area（ノッチ）と 100dvh を使えば、モバイルブラウザのアドレスバー変動にも寄せやすい。

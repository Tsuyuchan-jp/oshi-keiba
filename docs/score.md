## 読み（未確定）

全体は一本の掛け算パイプライン。スキル数で土台を作り、5ステで倍率を順に掛ける。ゴールは勝率検定ではなく、Nekoさんの強さの論理を数字にすること。

### スキル数（土台）

1. スクショのスキルを列挙する
2. 今のレースで無効なものを落とす
3. 今の脚質で無効なものを落とす
4. 緑はスキル数に入れない（後でステ加算に回す）
5. 残った有効スキルを数える
6. 金の枚数×2 を足して土台 S とする（確定: 金は有効に含めたうえで +2）

デバフを有効に入れるかは本文にない。[ocr.md](ocr.md) はデバフを読む前提。

無効は「有効リストに無いものを落とす」。リストの正は上の確定（U-tools 36コース×脚質）。

### ステ共通の型

各ステはだいたい次の形。

- 目標値は「このレース・脚質で要求される実数値」（表は本文に無い）
- 実数値はスクショの生値＋補正
- 補正: そのステの緑の枚数を実数値に足す。スピードは距離S、パワーはバ場S、賢さは脚質S も見る
- 達成比 `r = 補正後実数値 / 目標値`
- 達成時は S を r に応じて伸ばす。未達時はペナルティ（スピード節には未達の文が無い）

### 「実数値÷目標値÷４の値だけSを倍にする」

同じ型が4節ある。

| 節 | 原文の X | 直後 |
| --- | --- | --- |
| スピード | 実数値÷目標値÷４ | なし |
| パワー | 同じ | 「この値が1.0を下回るの場合…」 |
| 根性 | ÷１０ | 同じ「この値」 |
| 賢さ | 実数値÷目標値（÷なし） | 同じ「この値」 |

文法の芯は **「Xの値だけSを倍にする」**。÷４は X の一部で、「倍」は ×2 ではない。賢さに ÷４ が無いのに同じ「倍にする」があるので、「倍」= **倍率を掛ける** の口語。

`r = 実数値 / 目標値` と置く。

**「この値」は r であって r/4 ではない。** パワーで r/4 を 1.0 と比べると、実数値が目標の4倍未満なら常に未達側へ落ちる（ウマ娘では常時）。1.0 判定を書く意味が無い。だから ÷４ は達成側の加減だけ。未達は別文。

字面どおり `S *= r/4` は、目標ちょうど（r=1）で S が 1/4 になる。土台のスキル数を壊す。**字面は棄却。**

残りは、「賢さは r をそのまま倍率にする」を原型とし、スピード／パワー／根性はそれを **弱めた書き方** と見るか。

賢さを原型にすると、達成側の意図は `S *= r`（r=1 で据え置き、超過は比例）。弱め方の書き損じが ÷４。

| 候補 | 達成の式 | r=1 | r=1.2（2割超過） | 注記との相性 |
| --- | --- | --- | --- | --- |
| A | `S *= 1 + (r−1)/N` | ×1 | N=4 なら ×1.05 | 「達成メリット少ない」= 超過の効きを 1/N にする。÷N を **差（r−1）** に掛けた形。書きは r÷N になっている |
| A' | `S *= 1 + r/N` | N=4 なら ×1.25 | ×1.30 | 「の値だけ」を加算と読む。目標達成時点で既に +25%。メリット少ないとやや矛盾 |
| B | `S *= r`（÷N は無視） | ×1 | ×1.20 | 賢さと同一。÷４が死ぬ |
| C | `S *= r/N` | ×0.25 | ×0.30 | 棄却 |

**いまの本命は A。** 根拠は (1) 賢さ節が `S *= r` と読める (2) `1+(r−1)/1 = r` で賢さと同型 (3) ÷４／÷１０は超過の効きを薄くする係数 (4) 目標ちょうどで土台を壊さない (5) パワー注記と矛盾しない。

書きとの差: 本文は `r/4`、A は `(r−1)/4` を 1 に足す。**比そのものを割る**と **超過分だけを割る** の取り違え、と見る。口語の「÷４の値だけ」は後者（効きの1/4）になりやすい。

未達は「倍にする」の文ではなく次の文。こちらは別解析。

未達の「１－目標値をM倍」は、目標が千点台だと意味をなさない。**`1−r` を M 倍** の誤記と読む。

| 候補 | 未達（r<1） | 備考 |
| --- | --- | --- |
| D | `S *= 1 − M×(1−r)`（0 下限） | 足りなさに比例。注記の「デメリットの大きさ」と合う |
| E | `S *= r` のあと更に何か | 本文と距離がある |

注記との対応（N=達成の薄さ、M=未達の重さ）:

- パワー: 達成メリット小・未達デメリット大 → N=4, M=4
- 根性: 未達は軽い → N=10, M=2
- 賢さ: 両方大きい → 達成は N なし（r をそのまま）、未達 M=6
- スピード: 達成だけ N=4。未達文なし（書き漏れか、スピード未達はスタミナ側で見るか）

### 節ごとの補正

加算先と根性の要求は確定（上）。量だけ未確定。

- スピード: 距離がSか＋スピード緑の数 → スピード実数値へ
- スタミナ: スタミナ緑の数 → スタミナ実数値へ（掛かりの有無は目標側）
- パワー: バ場がSか＋パワー緑の数 → パワー実数値へ
- 根性: 緑も適性も無し。要求は根性
- 賢さ: 脚質がSか＋賢さ緑の数 → 賢さ実数値へ

「距離Sか」の加算量は未指定。緑1枚と同じ +1 か、適性Sで別ボーナスかは要確認。

緑はスキル数から除外したあと、枚数ぶん実数値に足す、が本文の流れ。緑1 = 実数値+1 はゲーム内緑スキル（数十点）より小さい。枚数加算でなく緑の効果量、の可能性もあるが、本文は「数を確認し加算」。

### スタミナ（離散ペナルティ）

他ステと違い、倍率は固定。

- 掛かりなし目標も未達: ×0.4
- 掛かりあり目標だけ未達（掛かりなしは達成）: ×0.8
- 両方達成: 本文に倍率なし → ×1
- 「スタミナ勝負のコース」なら代わりに ×0.2 と ×0.4
- `0,4` は `0.4` の誤記

掛かり発生時の要求 ≥ 未発生の要求、が普通。両方未達は「未発生が未達」に含まれる、と読める。両方達成の加点は書いていない。

### 作業用の式（採用ではない）

いま一番破綻が少ない読み（候補 A+D。金3・加算先は確定済み）:

```
S0 = 有効スキル数 + 2 × 金スキル数

r速 = (速 + 距離S補正 + 緑速の数) / 要求速
S1 = S0 × (r速≥1 ? 1+(r速−1)/4 : 1)   // 未達は本文なし

掛かりなし未達 → ×0.4（スタミナ勝負コースなら ×0.2）
掛かりありのみ未達 → ×0.8（同 ×0.4）
緑スタはスタミナ実数値へ加算して判定

rパ = (パ + バ場S補正 + 緑パの数) / 要求パ
S *= rパ≥1 ? 1+(rパ−1)/4 : max(0, 1−4×(1−rパ))

r根 = 根性実数値 / 要求根
S *= r根≥1 ? 1+(r根−1)/10 : max(0, 1−2×(1−r根))

r賢 = (賢 + 脚質S補正 + 緑賢の数) / 要求賢
S *= r賢≥1 ? r賢 : max(0, 1−6×(1−r賢))
```

これが評価点。場内で比にして Seed にする（[odds.md](odds.md)）。

・１ スクショからスキルの数を数える。
・２ レースに応じた無効スキルを読み込む。
・３ 脚質に応じた無効スキルを確認する。
・４ 緑スキルを計算から除外する。
・５ 有効スキルの数をカウントする。
・６ 金スキルの数×２を有効スキルの数に追加し、スキル数を保存する。

■要求スピードの確認

・１ 要求スピードを確認し、スクショから達成か未達を確認する。この際、距離Sか、スピードの緑スキルの数を確認し、パワーの実数値に加算する。
・２ 実数値÷目標値÷４の値だけSを倍にする。

■要求スタミナの確認

・１ レースと脚質に応じた掛かりは発生しない場合の要求スタミナと、掛かりが発生した場合の要求スタミナを確認する。
・２ スクショから要求スタミナがクリアされているかを確認する。この際、スタミナの緑スキルの数を確認し、パワーの実数値に加算する。
・３ 掛かり未発生の目標がクリアされていない場合、Sの値を0.4倍にする。掛かり発生時の目標のみクリアされていない場合、Sの値を0.8倍にする。もしもそのコースがスタミナ勝負のあるコースの場合、代わりに0.2倍と0,4倍にする。

■要求パワーの確認

・１ 要求パワーを確認し、スクショから達成か未達を確認する。この際、バ場Sか、パワーの緑スキルの数を確認し、パワーの実数値に加算する。

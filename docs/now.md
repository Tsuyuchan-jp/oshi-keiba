## 仮置き（第2回）

根拠の比較は [reports/2026-08-23/trial-odds-proposal-2.md](../reports/2026-08-23/trial-odds-proposal-2.md)。採用は **案 B**。

| 項目 | 値 |
|---|---|
| G | 3000 スペ（第1回と同じ） |
| 単位 | 100 スペ |
| S | 80000 |
| E | 100000 |
| w時下限 | 0.8 |
| w時指数 | 1 |
| λ | 1 |
| D | 20% |
| 均一 Display フロア F | 使わない |

連勝の参考オッズだけは、評価点の下限を **70** とする（第2回用の暫定値）。表示評価点・単勝・確定配当には適用しない。第2回終了後にメンバーの反応と倍率分布を確認して見直す。

連勝の票量基準は賭式別である。馬連 50,000、3連複 40,000、馬単・3連単各 7,000。上表の E=100000 は単勝用で、開催設定から変えても連勝には効かない。第2回の投票中、馬連・3連複の実票が開始時の試用値（25,000 / 7,000）に達して参考オッズの Seed が消えたため、2026-10-03 にこの2賭式だけを引き上げた。確定配当と払戻は変えていない。

管理のオッズタブは、投票中に参考オッズと実票オッズを並べて見比べる。単勝は全頭、実票がない頭の実票列は「—」。連勝は実票のある買い目だけ。実機確認OK（2026-10-03）。詳細は [odds.md](specifications/odds.md)。

分析ログは `odds-v3` / `analysis-log-v2`。連勝の人気上位10件と実票のある全買い目を保存する。未退避データが3MiBに達したら非公開R2へ自動退避し、成功後だけD1側を削除する。強制締切・時刻による自動締切のどちらでも同じR2退避を使う。失敗が続き4MiBへ達したら通常記録を止め、投票開始・締切直前・締切後だけを残す。第2回終了後、管理の分析ログタブから一括ダウンロードする。

開催は **1本ずつカレント**。公開済みの開催は残し、口座と残高は持ち越す。同時に投票できる開催は1つ。G は投票中に `/bet` で参加した人へ、その開催1回。入場だけでは配らない。デモ初期化と、締切を投票中へ戻す操作は本番に出さない。後者は締切だけを対象にし、出走と馬券を残す（ローカル実機確認OK。2026-09-24）。

式は [odds.md](specifications/odds.md)。OCR・評価点の自動算出、U-toolsキャラスペック補正、出走登録 UI は実装済み。材料が足りない頭は直置き。式の Neko 確定は未決（[score.md](specifications/score.md)）。台帳の場の会計は、有効投票と払戻（的中・特払い）で純還元率を見る。やり直し・出走取消は全額返還として別掲。場への移管は全投票と全払戻・返還の差額のまま。

アプリは **本戦だけ**。予選通過者の名簿を載せる。予選そのものはアプリに載せない。

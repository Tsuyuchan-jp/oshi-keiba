# アプリ版（人間確認用）

画面に出る版は `package.json` の `version` を `v` 付きで表示する（例: `0.2.0` → **v0.2.0**）。  
コード側の読み出しは `src/lib/version.ts`。上げるときは **このファイルの履歴を先に（または同時に）追記**し、`package.json` を同じ数字にする。

表示位置:

- メンバー（入場・場内・窓口）: PC 右下「管理者」の直上
- 管理: サイドバー「OSHI KEIBA · 管理」の横

SemVer（0.x）。git タグは任意。本番デプロイ手順そのものは [ocr.md](ocr.md) の「デプロイ（忘れない）」。

## 上げ方（チェック）

1. 下の **履歴** に新しい行を足す（日付・版・要約）
2. `package.json` の `version` を同じ数字にする
3. ローカルでメンバー右下と管理タイトル横の表示を目視
4. 本番に出すときは [ocr.md](ocr.md) の順（R2 → D1 `--remote` → `npm run deploy`）

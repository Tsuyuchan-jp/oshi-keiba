# Strength の混ぜ方（2手法の比較）

馬券の Seed に要るのは、最終的には **今回の出走メンバー内の比率** である。そこに至る経路が2つある。いまの仮置きは B。

どちらも、多基準意思決定（MCDA）でいう **単純加重和（SAW, Simple Additive Weighting）** の一種である。違うのは、重みを掛ける前に「何を 0〜1 にするか」だけ。

## A. 作者が想像していた流れ（基準点 → 加減点 → 合計 → 最後に相対化）

1. ステ・スキルそれぞれに **外の基準**（現代ステの目安、温存 8%、コースの平均バ身、など）を置く
2. 基準からの加点・減点で、ウマ娘1頭の **絶対点** を出す
3. 出走メンバーの絶対点を比べ、比率にして Seed にする

学術的な呼び方の目安:

- 教育測定の **絶対評価（criterion-referenced）**
- MCDA の SAW で、正規化に **固定レンジ（global / 基準参照）** を使う形
- ハンデキャッピングで、レースをまたいで比較できる **レーティング** を先に置く形

「1200 で 0 点、温存 8% で減点なし」のような錨は、まさにこの基準点である。

## B. いま Docs に仮置きしている流れ（枠ごとに場内で相対化 → 加重 → Seed）

1. スキル枠（バ身）とステ枠を、まだ混ぜずに出す
2. **その出走の中だけ**でスキルを相対化し、ステもその出走の中だけで相対化する
3. `3 × スキル相対 + 1 × ステ相対` を Strength にし、Seed にする

学術的な呼び方の目安:

- 教育測定の **相対評価（norm-referenced）** を、項目（スキル／ステ）ごとに先にやる
- SAW で、正規化に **その回の選択肢集合（local, グループ内 min-max または構成比）** を使う形
- 機械学習でいう **グループ内正規化**（そのレースを1グループと見る）

最後に Seed にする点は A と同じで、相対化のタイミングが早い。

## 具体例で見える差

3頭。バ身 10 / 9.8 / 9.5。ステは差が大きい。

- **B**: バ身が拮抗しているので、スキル相対はほぼ横並びになる。3:1 でも **差が付いているのはステ側**なので、順位はステが動かしやすい。これが「柔軟」に見える本体。重み 3:1 は「点の大きさ」ではなく **その週に差が付いている軸の、使い方の比率** に近い。
- **A**: バ身 10 と 9.5 が何点差になるかは、**外の基準の幅**で決まる。バ身 0〜20 を 0〜100 点にしていると 0.5 バ身は小さい。バ身 8〜12 を 0〜100 にしていると 0.5 バ身は大きい。柔軟さは基準表の設計に入り、その週のメンバー構成には自動では反応しない。

別の例。バ身 10 / 3 / 2。ステはほぼ同じ。

- **B**: スキル相対が大きく開く。ステを混ぜても1着候補はほぼバ身1位のまま。
- **A**: 同様になりやすい。ただしステの絶対点が極端に広いスケールだと、意図せずステが食う。

## メリット・デメリット

| | A 基準点→絶対点→最後に相対化 | B 枠ごとに場内相対化してから混ぜる |
|---|---|---|
| 1頭だけの意味 | 「この子は 75 点」と言える。週をまたいで比較しやすい | 場が変わると数字の意味が変わる。単独では語りにくい |
| 単位の処理 | 基準表でバ身とステを同じ「点」に換算する必要がある。表が悪いと、レンジの広い項目が合計を支配する | 先に場内で 0〜1 に揃えるので、3:1 が「このレースでの差の効き」として効きやすい |
| 基準づくり | 現代基準値・平均バ身など、作者の錨を直接埋め込める。温存 0〜8% 減点ゼロと相性がよい | 外の基準はステ枠・温存の **中** には残る。スキル枠は「場の中の抜け」が本体 |
| メンバーが変わったとき | 絶対点は他人が来てもあまり動かない。弱い1頭が増えても、強い2頭の点は同じ | 無関係な1頭で相対が動く（意思決定論でいう **IIA を満たさない**）。極端に弱い馬や突出した馬が、他の差を伸ばしたり潰したりする |
| スキル拮抗時 | 基準幅次第。幅が広いとステ差が無視され、狭いとステが勝ちすぎる | スキル差が小さい週は、自動的にステが順位を決めやすい |
| 実装 | 基準表のメンテナンスが本体 | 出走が揃ってから計算する。1頭では Seed が出せない（馬券には元々出走が要る） |

A の落とし穴は「基準からの加減点なら単位を気にしなくてよい」に見えて、**実は基準の幅が隠し重みになる**こと。B の落とし穴は「3:1 でスキル厚め」に見えて、**差がない週はステが本体になる**こと。どちらも正しい間違いではなく、何を固定したいかの違い。

## 中間（よくある第三の形）

各枠を、場ではなく **固定レンジ** で 0〜1 にする（例: バ身はいつも 0〜15 を 0〜1、ステ点はいつも 0〜100 を 0〜1）。そのあと 3:1 で足し、最後に出走内比率にする。

これは A の基準点と B の「足す前に 0〜1」を足したもので、MCDA 教科書の SAW にいちばん近い。週をまたぐ点数の意味は A 寄り、重みがレンジに食われない性質は B 寄り。IIA は絶対点の段階では比較的安定する。

## いまの仮置き

B を仮置き。理由は、Seed がもともと場内比率であることと、スキル拮抗時にステへ倒れる動きが、作者の「ステはタイブレーク寄り」と両立しやすいこと。

温存の錨（0〜8% / 16% / 40%）は **ステ枠の中の A（基準点）** のままでよい。混ぜの外側が B でも、枠の中は絶対評価で書いて構わない。

A や中間に切り替えるなら、先に「バ身何度を 100 点と見るか」を錨として置く。それが無いと A は実装できない。

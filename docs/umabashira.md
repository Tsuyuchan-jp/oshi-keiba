# ウマ柱（競馬新聞風）

管理者が note／手元用に撮る、出走全頭の縦1列紙面。号外（[gougai.md](gougai.md)）とは別物。メンバー画面には出さない（方針は号外と同じ）。

**いまの段階:** 実装は可能。掲載項目は未確定。見た目の正はまだ無い。

---

## 可否

**実装できる。** 新しい勝率計算は不要。既に D1 にある開催・出走・評価点材料と、算出済みの評価点／参考オッズを並べて HTML にし、プレビューと PNG にする作業。号外と同じ配送路（管理タブ・モック先行・クライアント書き出し）。

ただし添付の実紙馬柱の複製にはならない。実紙の下半分は過去走5〜6走で、アプリにはそのデータが無い。できるのは「本戦1走分の材料を、馬柱の読み方に寄せて1枚に畳む」こと。

| 論点 | 判断 |
|---|---|
| データ不足で止まるか | 止まらない。識別・脚質・5ステ・適性・スキル・コース条件は揃う |
| 新規計算が要るか | 要らない。既存の `scoreFromHorse` / ボードの参考オッズを読むだけ |
| 頭数 2〜18 | 列数可変。実紙の16頭固定とは違う。モックで幅を試す |
| 枠番色 | アプリはウマ番のみ。枠番は扱わない（[playbook.md](playbook.md)） |
| 直置き頭 | `score_input` が無いとステ／スキル列が空。評価点の数字だけ出る |
| 号外との干渉 | 管理タブ追加と PNG 手段だけ共有。紙面は別 |

---

## 進め方

号外と同じ順。いまは 1。

1. **データ洗い出しと掲載案**（このファイル。次は掲載の確定）
2. **レイアウト仮決め** … 添付馬柱を骨格にし、無いブロックはアプリ項目へ読み替え
3. **HTML モック** … `docs/mocks/umabashira/` で案を並べて比較
4. **管理タブ** … 差し込み・プレビュー・PNG。サーバー焼きは最初はしない（号外と同じ）

---

## 目的と置き場所（仮）

- 用途: 予想 note や当日オペ用の1枚。アプリは生成・プレビュー・書き出し。
- 誰: 管理者のみ。管理画面に生成専用タブ（例: `/admin/umabashira`、ラベル「ウマ柱」）。号外タブとは別。
- いつ: タブは開催の最初から出してよい。列が埋まるのは出走登録が進んだ時点。投票開始前はオッズ欄が空。
- 出さない: メンバーの場内・パドック・窓口。自動ポップアップもしない。

用途が「管理者が内部で見る」か「note に載せる」かで、評価点を出すかが変わる。下の掲載案を見て決める。

---

## 実紙との対応

添付画像のブロックを、アプリで何に置き換えるか。

| 実紙 | アプリ | 扱い |
|---|---|---|
| 開催日・R・レース名 | 開催名。日付専用列は無い（`created_at` / 締切はある） | 開催名を出す。日付は手入力か省略 |
| 場・芝ダ・距離・馬場 | `score_setup` のコース・天候・バ場 | 出す |
| 頭数・負担重量 | 出走頭数。斤量は無い | 頭数だけ |
| 枠番色・枠番 | 無い。通しのウマ番だけ | ウマ番。枠色は使わない |
| 脚質アイコン（逃先差追） | `score_input.styleKey` | 出す |
| 馬名（縦書き） | `uma_name` | 出す |
| 血統（父・母父） | カタログに無い | 出さない |
| 性齢・毛色・馬体重 | 無い | 出さない |
| 馬主・生産 | 無い | 出さない |
| 騎手・調教師 | `runner_name`（出走者） | 騎手欄の位置に出走者 |
| 騎手成績・調教師成績 | 無い | 出さない |
| HB指数 | 評価点 `strength` | **出すか要判断**（メンバー画面には出さない数字） |
| 予想記号 ◎○▲ | 無い。単勝参考の並びから印は付けられる | 新規確率ではないが、出すかは判断 |
| 過去走（日付・着順・タイム・通過・上がり） | 予選はアプリ外。本戦の過去走も無い | 出さない。下段はスキル／ステに差し替え |
| 調教（CW など） | 育成スクショはある。タイム列は無い | スクショは紙面に焼き込まない（号外と同じ） |
| 右端の凡例 | アプリ用に書き直す | モックで要否 |

## 参照できるデータ

計算し直さず読めるもの。ソースは型と画面の正。

### 開催（`events` / `score_setup`）

| 項目 | 出所 | 備考 |
|---|---|---|
| 開催名 | `EventRow.title` | |
| フェーズ | `status` | setup / voting / closed / published |
| コース場・芝ダ・距離 | `getScoreCourse` | 例: 東京・芝・2400 |
| 天候・馬場・季節 | `conditions` | 晴／良／春 など |
| スタミナ勝負フラグ | `requirements.staminaRace` | 紙面に出す必要は薄い |
| ステ目標値 | `requirements`（脚質別スタミナ含む） | パドック詳細と同じ |
| 有効スキル id・キャラスペック | 保存時スナップショット | 内訳表示用。紙面向きではない |
| 頭数 | 取消以外の出走数 | 2〜18 |
| 締切時刻 | `voting_closes_at` | ヘッダに出すなら可 |
| 賭式・G・S・E・D | `EventRow` | **紙面に出さない**（号外と同じ） |

### 出走1頭（`horses`）

| 項目 | 出所 | 備考 |
|---|---|---|
| ウマ番 | `HorseBoard.number`（`sort_order`） | 1〜頭数。枠番ではない |
| ウマ娘名 | `uma_name` | |
| 出走者名 | `runner_name` | |
| 衣装 | `chara_id` / `dress_id` → カタログ | 衣装名を出せる |
| 取消 | `scratched` | 列から外す |
| 着順 | `finish_place` | 予想紙には出さない |
| 評価点 | `strength` | 直置きも同じ列 |
| 材料の経路 | `seed_source` | auto / manual |
| 意気込み | `paddock_comment` | 号外は紙面へ自動挿入しない |
| 育成スクショ | R2 `shot_key` | メンバーの表には出さない。紙面焼き込みも非推奨 |
| トレーナーアイコン | R2 `trainer_icon_key` | 小さくなら可 |

### 評価点材料（`score_input`。OCR または手入力）

直置きだけで材料が無い頭は、ここが空。

| 項目 | 内容 |
|---|---|
| 5ステ | 速・スタ・パ・根・賢 |
| 適性10 | 芝ダ・短マイル中長・逃先差追 |
| 出走脚質 | 逃／先／差／追 |
| スキル名と id | 有効・金相当・緑・戦略例外・不採用に分けられる |
| 不採用スキル | OCR が落とした名前。紙面向きではない |

コースに効く適性3つ（バ場・距離・脚質）は `scoreFromHorse` が既に拾っている。パドック詳細と同じ。

### 算出済み（新規式なし）

| 項目 | 出所 | 備考 |
|---|---|---|
| 評価点の内訳 | `ScoreBreakdown` | スキル土台、緑加算後ステ、各倍率、キャラスペック倍率 |
| スキルパワー | `breakdown.skill.base`（S0） | パドック詳細に既出 |
| 有効／金相当／戦略点数 | 同 `skill` | パドック詳細に既出 |
| 成立した緑 | `appliedGreens` | |
| 単勝参考オッズ | `HorseBoard.referenceOdds` | 投票開始後。メンバー向けは「オッズ」 |
| 確定配当 | `confirmedOdds` | 締切後。予想紙には向かない |
| Seed / Display / 実票 | ボード | **紙面に出さない** |

集約の既存入口: `paddockView`（メンバー向けに既に畳んでいる）と出走タブの内訳（`pipeHtml`）。ウマ柱用に計算を足さない。

### 画像

| 種類 | 解決 | 備考 |
|---|---|---|
| デフォルメ petit | `resolvePetitImageUrl` | `_0010`。パドックと同じ |
| 立ち絵 stand | 号外側の課題。ウマ柱第1段では使わない想定 | |
| 育成スクショ | 管理 `/admin/shot/…` | 紙面には載せない案 |

血統・性齢・毛色・馬体重・騎手成績・調教タイム・過去走の着順／タイムは、参照できない。予選結果もアプリ外。

## 掲載案（未確定）

実紙の密度を、アプリにあるもので埋める仮。確定は次の会話。

### 出す（案）

- ヘッダ: 開催名、場・芝ダ・距離、天候・馬場、頭数
- 各列: ウマ番、脚質、ウマ娘名、出走者、petit、5ステ、今走の適性3、スキル名（有効を優先。金／固有が分かる印）
- 投票開始後: 単勝参考オッズ

### 判断が要る

| 項目 | 出すと | 出さないと |
|---|---|---|
| 評価点 | 実紙の HB 指数に相当。管理の内部点を note に出すことになる | パドックと同じ「材料」だけの紙面になる |
| 人気印 ◎○▲ | 参考オッズの順位を印にするだけ。新規確率ではない | 新聞っぽさは落ちる |
| スキル内訳の枚数（有効・金） | パドックのスキルパワーと揃う | 名前リストだけになる |
| 意気込み | 1行なら収まる | 号外と同じく記者の参照専用 |
| 日付 | 手入力欄が要る | 開催名だけで足りる |

### 出さない（案）

- 枠番色、血統、性齢、毛色、馬体重、騎手／調教師成績、過去走、調教タイム
- Seed、Display、控除 D、誰が何を買ったか、着順
- 育成スクショの焼き込み
- 勝率・シミュレーション・新しい指数

## レイアウトの仮（次の段で詰める）

骨格だけ。数値・フォントはモックで決める。

- 向き: 横長1枚。列 = 出走1頭。CSS Grid で列数 = 頭数
- 上: 開催ヘッダ（実紙の左上）
- 各列 上→下: ウマ番＋脚質 → 名前＋petit → 出走者 → （評価点／オッズ） → ステ＋適性 → スキル
- 実紙の「過去走ブロック」は置かない。同じ高さをスキルリストに使う
- 18頭でも読める最小字をモックで確認する。スマホ幅に収めない（号外の 26rem とは違う）

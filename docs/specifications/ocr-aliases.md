# OCR 例外対応リスト（スキル名）

Gemini が返したスキル名が、カタログ正式名とずれたときに直す経路。正規化（空白除去・全角英数→半角など）のあと、次の順:

1. **エイリアス表**（下表）で完全一致した文字列だけ正式名に差し替え
2. **千.万. 骨格**（後述）
3. ファジー（編集距離≤1・Dice≥0.45）

正本はコード: `src/lib/skillFuzzy.ts`（`OCR_SKILL_ALIASES`・`applySenmanSkeleton`）。ブラウザ側の読取確認も同じ（`ocrAdmin.ts` の `ALIAS` / `applySenman`）。**片方だけ直さない。** Docs を直したらコードも揃える（または逆）。

ファジーで拾えるもの・骨格で拾えるものは表に載せない。**OCR落ちに出た生文字列**で、骨格でもファジーでも拾えないものだけ足す。

## 千.万. 骨格（千鍛万錬）

カタログで `/^千.万.$/`（ちょうど4文字）に合うのは **千鍛万錬だけ**。Gemini が成語（千客万来・千紫万紅など）に寄せた誤読は、カタログにその文字列が無いとき自動で千鍛万錬へ寄せる。新しい千○万○の落ちは、原則エイリアス追加不要。

## 足し方

1. 読取確認の **OCR落ち** バッジから文字列をコピーする（目視のひらがな／カタカナは当てにしない）
2. `千.万.` なら骨格で足りるか確認（足りるなら表に足さない）
3. `skill-catalog.json` の正式名を確認する
4. 上の表と `OCR_SKILL_ALIASES` / `ALIAS` に同じ行を足す
5. `skillFuzzy.test.ts` に1本足す（先頭／2番目以降で unique／inherit が分かれるものは両方）
6. このファイルの表を更新する

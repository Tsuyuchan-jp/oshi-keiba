# 投票とオッズ

払いの約束は **①**: 確定・払いは実票のみ。Seed 込みでは払わない（増刷しない）。不成立は **特払い B**（[playbook.md](../operations/playbook.md)）。開催数字は [now.md](../now.md)。

メンバー向けの言葉はすべて **オッズ**。投票中は単勝・連勝とも参考オッズ、締切後は確定配当と呼ぶ。

## 前提

本体はパリミュチュエル。Neko長明さん投稿:

`オッズ = (総投票額 TV × (1 − 控除率 D)) / (その馬への投票額 V)`

D の目安は 20%。少人数だと実票だけでは板が荒いので Seed が要る。Seed の入力は [score.md](score.md) の評価点。Neko さんの note の 3連単予想は Seed にしない。

## 呼び方

- **投票中**: 参考オッズ（評価点＋これまでの実票の人気の目安。払う約束ではない）
- **締切後**: 確定配当（実票だけのパリミュチュエル。D=20%。この数字で払う）

同じ「オッズ」で払わない数字を出さない。参考と確定は閑散だと離れる。金銭ではないので完全一致は必須ではない。

## 第2回向けの単勝参考

連勝の実票を、単勝参考の山（TV）と各馬の Display に乗せる。確定には入れない。均一フロア F は使わない。比較は [trial-odds-proposal-2](../../reports/2026-08-23/trial-odds-proposal-2.md)。

λ=1・額 600 の割り振り:

- 馬連 AB: 300+300
- 馬単 A→B: 400+200
- 3連複: 各 200
- 3連単: 300+200+100

```
TV = 単勝実票合計 + λ × 連勝実票合計
w時 = 下限 + (1 − 下限) × 残り^指数
w票 = max(0, 1 − TV / E)
w = w時 × w票
Seed_i = S × 評価点_i / Σ 評価点
Display_i = Seed_i × w + 単勝Real_i + Imputed_i
参考オッズ_i = (Σ Display × (1 − D)) / Display_i
```

λ は定数 1（管理画面では触らない）。

## 投票中の連勝参考

馬連・馬単・3連複・3連単は、評価点から賭式ごとの仮想Seedを配り、実票と混ぜた参考オッズを出す。指数は `γ=2`、各賭式のSeed合計は開催の `S` を使う。順番のある買い目は着順どおりの確率、順不同の馬連・3連複は成立する順序を合計する。

```
q_i = 評価点_i^γ / Σ 評価点^γ
連勝Seed_c = S × P(c)
w連勝 = w時 × max(0, 1 − その賭式の実票合計 / E賭式)
Display_c = 連勝Seed_c × w連勝 + Real_c
連勝参考オッズ_c = {(S × w連勝 + その賭式の実票合計) × (1 − D)} / Display_c
```

`E賭式` は馬連25,000、馬単・3連複・3連単は各7,000。連勝Seedは単勝参考へ混ぜず、連勝の**実票だけ**を従来どおりImputedとして単勝参考へ反映する。締切後の確定配当・払戻は、連勝も実票だけで計算する。

窓口では、最後の選択枠だけが空いた段階で残り候補の連勝参考オッズ一覧を、全枠選択後は選択中の1点を表示する。馬一覧には賭式に関係なく単勝参考オッズを表示し、両方を5秒ごとに更新する。表示は `9999.9+` で上限を設ける。詳しい経緯と場内表示の未対応項目は [exotic-seed.md](exotic-seed.md) を参照。

場内の連勝4タブは出走登録中・投票中・締切後に出す。出走登録中と投票中はこの節の参考オッズ、締切後は下記の確定配当を表示する。馬単・3連単の「直近投票」は、買い目ごとの最終投票時刻が新しい順に最大9件とし、同じ買い目への連続投票は1行へ集約する。

## w と E・S

- 時間で薄く減らす＋票量で減らす。合成は掛け算
- 時間側: 下限は厚め。時計だけでは 0 にしない
- 票量側: 下限 0。人数ではなく TV。E に達するとこちらは 0 まで落とせる
- G と S・E は独立。配布を変えても自動では動かない。G はその開催の投票中に参加した人へ1回（来ない人には配らない）
- S・E・下限・曲線は管理者 UI で触れる

## 確定配当

```
払戻しの原資 = その賭式の実票合計 × (1 − D)
確定配当 = 払戻しの原資 / 当たりの実票
払戻 = floor(賭け額 × 確定配当)
```

当たりの実票がゼロなら特払い B（その賭式に賭けた人へ、控除後を戻す。100 → 80、端数切り捨て）。出走取消はそのウマ娘を含む票の **全額** 返還（特払いではない）。

## 場の会計

結果公開時に、その開催でメンバーへ戻らなかったスペを管理者（場）の口座へ一度だけ移す。

```
場への移管額 = その開催の全投票額 − その開催の全払戻・返還額
```

全払戻・返還額には、的中払戻、特払い、出走取消、投票のやり直しを含む。この差額は控除と払戻時の端数を含むため、外れ票と D を別々に足して二重計上しない。開催ごとの確定値を保存し、後から D や計算式を変更しても過去の精算額は再計算しない。

管理の台帳では、人間が見る投票・払戻からやり直しと出走取消を除く。

```
有効投票 = 全投票額 − やり直し − 出走取消
払戻     = 的中払戻 + 特払い
純還元率 = 払戻 / 有効投票
全額返還 = やり直し + 出走取消
```

場への移管の式は変えない。純還元率は公開後だけ出す（投票中は「—」）。残高 KPI（管理スペ・総発行・メンバー所持・未精算プール）は従来どおり。投票中の票は未精算プールとし、結果公開までは管理者残高へ含めない。

台帳のこの内訳表示は実装クローズ（2026-09-14）。控除 D=20% のパリミュチュエル本体は変えていない。

## 内部計算（人間用）

| 記号 | 何の数字か |
|---|---|
| 評価点 | この出走の中での相対評価。メンバーには出さない。管理画面の項目名が Strength のままのことがある |
| Seed | 仮想の初期投票額。払わない |
| S | Seed の合計 |
| Real | その馬への単勝実票 |
| Imputed | 連勝実票から単勝参考用に割り振った額（確定には使わない） |
| TV | 単勝参考の寄せに使う実票相当（第2回は単勝＋λ×連勝） |
| w | Seed を残す割合。w時 × w票 |
| E | TV がこれに近づくと Seed を薄くする目安。賭け上限ではない |
| Display | 参考オッズの分母・分子に使う混ぜた額 |
| D | 控除（0.2） |
| G | その開催の参加で配る額。投票中の初回参加で1回。入場だけでは入らない |

開場直後の単勝倍率は評価点の比だけで、S の大きさでは変わらない。S は実票が混ざったあとの評価並びの重さ。

## 開催後の分析ログ

管理の **分析ログ** は、投票開始時、投票・やり直し・出走取消時、締切直前、締切後に、その時点でメンバーへ出した板を保存する。第3回以降の S / E / D / w時 / 指数の比較と、締切直前の参考オッズと確定配当の差の検証に使う。時間だけで変化する `w時` の連続観測は通常行わない。

実装はクローズ（実機確認OK。2026-09-08）。S / E / D / w時下限 / 指数 / λ は投票開始後に変更しない。CSVの列・数式変更時の扱い・開催後の分析手順は [analysis-log.md](analysis-log.md) を正とする。

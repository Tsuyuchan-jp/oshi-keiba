# オッズ

第3回以降の式。第2回までの記録は末尾。数字の初期値は [now.md](../now.md)。

## 約束

投票中も締切後も同じ式で、確定配当に Seed を残す。払戻は投票額を超えてよい。

- 単勝も連勝も、倍率 = `(Seed + その買い目の実票) で山分け × (1 − 控除 D)`
- 空の板の倍率は `(1 − D) / その買い目の確率`。S の大きさでは変わらない
- 払戻 = `floor(投票額 × 公開時点の倍率)`。1枚ずつ。同じ当たり買い目は同じ倍率
- 実票ゼロの当たりは、その賭式をすべて外れにする（特払いしない）
- 取消・やりなおしは全額返還のまま

## 式

単勝の Seed は、出走中の頭の評価点の比で分ける。評価点 0 の Seed は 0。取消した頭は分母から外す。

連勝の確率は、評価点を γ=2 で重みづけた Harville。馬連・3連複は順不同なので、並びの確率を足す。評価点の下限は掛けない。

```text
シェア = その買い目の Seed + 実票
プール = その賭式の S + 実票の合計
倍率   = プール × (1 − D) / シェア
```

実票が増えると、賭けた買い目の倍率は下がり、賭けていない買い目の倍率は上がる。

## S と控除

S は賭式ごと。入力するのは単勝だけ。ほかの4つは、保存したときに次の比を掛けて四捨五入し、開催の列へ書く。画面を開くたびに掛け直さない。比はコードの定数。

| 賭式 | 単勝に対する比 |
| --- | ---: |
| 馬連 | 1.37 |
| 馬単 | 0.59 |
| 3連複 | 2.60 |
| 3連単 | 2.69 |

比は JRA の発売票数（2026-09-27 阪神、2026-10-03 東京、2026-10-03 京都の3日、1日12レースの平均）から取った。単位は比で消える。

単勝 S の初期値 135,000 は、控除 20% で空の 10 倍が、3,000 スペ一口で 8 倍になる大きさ。今後の開催で動かすのは単勝 S だけ。

S と控除は投票開始前だけ変えられる。開始後は入力を止め、保存も拒む。

## 移管

移管 = 全投票 − 全払戻・全額返還。正なら管理者残高へ足す。負（新規発行）は管理者残高を減らさず、総発行スペが増えたものとして台帳に出す。

## 公開時に残すもの

第3回以降は、公開時に賭式ごとの当たり買い目・使った倍率・その賭式の払戻合計と、開催の移管を保存する。公開後の盤・馬券・台帳は、その保存を読む。全買い目は保存しない。

分析ログは投票中の過程を残す。第3回以降の式では、使っていない w・E・λ・評価点下限を 0 として書く。CSV の列の整理は別作業。

## 第2回まで

第1回・第2回は `odds-v3` のまま再計算しない。確定は実票だけ、不成立は特払い B（控除後の 8 割、端数切り捨て）。お金の正は、当時の払戻と `event_settlements`。式の詳細は [0.9.0 の記録](../history/changelog.md) を参照する。

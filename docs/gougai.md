# 号外（競馬新聞風）

管理者が note 用に撮る、チャンミ号外のオマージュ紙面。メンバー画面には出さない。見た目はゲームに寄せ、中身の台詞・インタビューは寄せない。

正本の見た目確認は [mocks/gougai/index.html](mocks/gougai/index.html)。ゲーム素材は `public/twinkle/`（PNG は git 管理外。詳細は同フォルダの `NOTICE.txt`）。

---

## 目的と置き場所

- 用途: 結果公開記事（note）用の1枚。アプリは生成・プレビュー・文言差し替え・書き出し。
- 誰: 管理者のみ。管理画面にタブを追加する（例: `/admin/gougai`、ラベル「号外」）。
- いつ: タブ自体は開催の最初から出してよい。紙面が埋まるのは **1着が入力された時点**（`published` 待ちにしない）。
- 出さない: メンバーの場内・パドック・窓口。自動ポップアップもしない。

---

## 紙面上から下

1. **マストヘッド** … 緑帯。誌名はオマージュ（初期「月刊トゥインクル　号外」）。文字列は差し替え可能にしておく。
2. **メインビュー** … 背景＋立ち絵＋右の青帯＋縦書き3列。**ここの右側（青帯と3列）はモックで確定。** 下の「メインビュー」を正とする。
3. **本文** … `230_headline_body.csv` 由来の4文を連結。差し込みは開催名・ウマ娘名・トレーナー名。`<color=#ff9900>` はオレンジ。
4. **トレーナー帯** … 新聞欄外（D）。一段。左が人物、右が開催4値（ラベルなし）。

2着・3着の枠は置かない。記者寸評の二段目も置かない。語り手は本文だけ。

---

## メインビュー（確定）

レイヤ（下から）: 背景 → 青帯 → 立ち絵 → 縦書き3列。

| 項目 | 値 |
|---|---|
| カバー高さ | `20rem`（`--cover-h`） |
| 上下パディング | `0.6rem`（`--cover-pad-y`）。9文字サイズは `(高さ − パディング×2) ÷ 9` |
| 背景 | `public/twinkle/frames/gogai_bg.png`（アニメ調・オリジナル）。青帯の裏には回さず、カバー左 **85%**（紙面 26rem×高さ 20rem なら約 11:10） |
| 立ち絵 | `chara_stand` が第一候補。モックは仮 PNG。位置 `left: -4%`、下寄せ |
| 青帯 | 右端、幅 **15%**、色 `#4a22e1`。左端は2列目の左寄り。3列目は帯の外（立ち絵側）に出してよい |
| 3列の並び | 右→左。上端揃え |

### 縦書き3列

1. **右列（画像）** … `public/twinkle/subtitles/324.png`（仮。本番の選び方は未決）。元画像は縦が約 3/4 に潰れているので高さ方向に **4/3** 伸ばす。黒背景は `mix-blend-mode: screen` で青帯に抜く。
2. **中列** … `229_overlay_vertical.csv` の `\n` **より前**（`<character_name>` → ウマ娘名）。
3. **左列** … 同 CSV の `\n` **より後**（例: id=571 なら「見事チャンピオンに」）。

2・3列目の見た目（確定）:

- フォント: **M PLUS 1p 900**（Google Fonts）。ゲームのロダンわんぱく Pro e の代用。丸ゴ過多は却下済み（Rounded / Zen Maru / Dela は見送り）。
- 色: 赤字 `#e31b23`、黄縁 `#ffe44a`、太さ `0.07em`、影なし。
- 2列と3列は同じサイズ。縁のはみ出しで上下余白が消えないよう、タイトル帯は `overflow: hidden`。

立ち絵の欠け時: `chara_stand` → 同キャラ既定衣装 stand → petit `_0010` → 名前プレースホルダ。全衣装を git に載せない。優勝頭の ID だけ解決する。

ゲーム subtitle の大会名画像（例: 027「カプリコーン杯」）は推し大会向けに使わない。右列の 324 はモック用の仮。

## 本文（確定）

`230_headline_body.csv` 由来を改変し、空白区切りで連結。太字は **IBM Plex Sans JP 700**（本文専用。縦書き3列の M PLUS 1p 900 とは分ける）。オレンジは `#ff9900`。差し込みは `{イベント名}` `{トレーナー名}` `<character_name>`。

1. 33001 … `{イベント名}` 本戦！並みいる猛者を退け勝ったのは`<character_name>`！
2. 100202 … 「`{トレーナー名}`」との信頼が生んだ最高の結末だ。
3. 110200 … 優勝に相応しい、素晴らしい走りを見せてくれた。
4. 120201 … こんな走りを見られたことに、ただただ感謝したい。

本文帯（確定）: 案 D から上辺の走路ストライプを外す。緑地 `#e8f3ea` の中に白カード（枠 `#d7e6cc`）。

## トレーナー帯

イラストは使わない（D）。高さは人物ブロック一段。

| 位置 | 内容 |
|---|---|
| 左 | 優勝ラベル・アイコン・ウマ番・出走者名（大きく）・ウマ娘名・脚質 |
| 右 | 開催名・コース・天候／バ場・頭数。**項目名は出さない**。2×2。字サイズはウマ娘行と同じ `0.78rem` / 700 |

単勝・人気は出さない。

## 文言・語り手

- ウマ娘が喋る勝利コメント、公式インタビュー全文、パドック意気込みの自動引用、優勝者への DM 取材はしない。
- 意気込み（`paddock_comment`）は左ペインの **参照専用**。紙面へは自動挿入しない。記者が読んで本文を書く。
- 縦書き本文の選択: モックは csv **571**。本番の id の決め方（ラウンド・着差など `champions_news_win_title.json`）は未決。

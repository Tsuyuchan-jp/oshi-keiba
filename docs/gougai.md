# 号外（競馬新聞風）

管理者が note 用に撮る、チャンミ号外のオマージュ紙面。メンバー画面には出さない。見た目はゲームに寄せ、中身の台詞・インタビューは寄せない。

**いまの段階:** 第1段クローズ（ローカル実機確認OK。2026-09-05）。管理タブ `/admin/gougai`（左プレビュー・右編集・PNG / WebP）。見た目の正は [mocks/gougai/index.html](mocks/gougai/index.html) の `.paper`。本番のルートは `.gougai-paper`。同ファイル下の「正（生成画像）」「重ね」はトレーナー帯 CSS の照合用で、本番紙面には出さない。ゲーム素材は `public/twinkle/`（PNG は git 管理外。詳細は同フォルダの `NOTICE.txt`）。立ち絵は `public/images/umamusume/stand/`（PNG は git 管理外）。細かい修正は別指示で行う。

実装はモックの HTML／CSS を移植し、プレースホルダを開催・1着のデータで埋める。レイアウトを作り直さない。

---

## 目的と置き場所

- 用途: 結果公開記事（note）用の1枚。アプリは生成・プレビュー・文言差し替え・書き出し。
- 誰: 管理者のみ。管理画面のタブ `/admin/gougai`、ラベル「号外」。ナビはウマ柱の下。
- いつ: タブ自体は開催の最初から出してよい。紙面が埋まるのは **1着が入力された時点**（`published` 待ちにしない）。1着が無いときは「1着未入力」バナーとプレースホルダ紙面。
- 出さない: メンバーの場内・パドック・窓口。自動ポップアップもしない。意気込みは紙面にも編集欄にも出さない。

---

## 紙面（上から下・確定）

紙面幅はモックどおり **max 26rem**。背景色 `#f7f7f4`。`.gougai-paper` に `container-type: inline-size`（トレーナー帯の `cqw` 用。モックは `.paper`）。

1. **マストヘッド**
2. **メインビュー**（カバー）
3. **本文**
4. **トレーナー帯**

2着・3着の枠は置かない。記者寸評の二段目も置かない。語り手は本文だけ。

## メインビュー（確定）

高さ `--cover-h: 20rem`。上下パディング `--cover-pad-y: 0.6rem`。9文字サイズは `(高さ − パディング×2) ÷ 9`。

レイヤ（下から・z 順）: 背景 → 青帯 → 立ち絵 → 縦書き3列。HTML の並びはモックどおりでよい（z-index でこの順）。

| 項目 | 値 |
|---|---|
| 背景 | `public/twinkle/frames/gogai_bg.png`。青帯の裏には回さない。左 **85%**、`object-fit: cover`、`object-position: center 40%` |
| 青帯 | 右 **15%**、`#4a22e1`。左端は2列目の左寄り。3列目は帯の外（立ち絵側）に出してよい |
| 立ち絵 | `left: -4%`、`bottom: -6%`、`height: 106%`、`object-fit: contain`、ドロップシャドウ |
| 3列帯 | 右寄せ幅 **36%**。`direction: rtl` で右→左、上端揃え、`gap: 0.35rem`、`overflow: hidden` |

### 縦書き3列

1. **右列（画像）** … 初期 `324.png`。編集で変更可。元画像は縦が約 3/4 に潰れているので高さ方向に **4/3** 伸ばす。ラッパー高さは inner の **7/9**、幅 `1.55rem`。黒背景は `mix-blend-mode: screen`。編集の一覧も同じ比率に伸ばして表示する。
2. **中列** … `229_overlay_vertical.csv` の `\n` **より前**（ウマ娘名）。
3. **左列** … 同 CSV の `\n` **より後**（571 なら「見事チャンピオンに」）。

2・3列目: **M PLUS 1p 900**。赤字 `#e31b23`、黄縁 `#ffe44a`、太さ `0.07em`、影なし、`paint-order: stroke fill`。2列と3列は同じサイズ。

立ち絵の欠け時: `chara_stand` → 同キャラ既定衣装 stand → petit `_0010` → 名前プレースホルダ。全衣装を git に載せない。優勝頭の ID だけ解決する。ローカルも同じ順（`public/images/umamusume/stand/chara_stand_{chara}_{dress}.png`）。

ゲーム subtitle の大会名画像（例: 027「カプリコーン杯」）は自動では選ばない。右列の手選択には残す。

## トレーナー帯（確定）

見た目はモック CSS。`gogai_trainer_band.png` は部品合成の照合用（焼き込み文字あり・本番では使わない）。地・金線・仕切り・バッジ・文字は CSS。月桂冠とキラキラだけ画像。

| 位置 | 内容 |
|---|---|
| 左 | `gogai_wreath.png`（左枝反転で右も同じ。中央にアイコン用の隙間。下では繋がない）＋差し替えアイコン。優勝バッジ、出走者名、ウマ娘名 |
| 右 | ラベルなし3行: 開催名 / `{場}　{芝/ダ}{距離}m` / `{季節}・{天候}・{バ場}　｜　{頭数}頭`。キラキラ `gogai_sparkles.png` |

数値・制約（モックから移植）:

- 基準高さ `--band-h: calc(100cqw * 316 / 1536)`。`cqw` のコンテナは **`.gougai-paper`**（モックは `.paper`）。帯自身に `container-type` を付けると `cqw` がビューポート幅になり下が伸びる。
- 帯は `min-height: var(--band-h)`、`height: auto`。開催名が2行のときだけ中身に合わせて伸びる。固定 `aspect-ratio: 1536/316` は2行を切るので紙面には使わない（モック下の重ね比較だけ使用）。
- 月桂冠高さは基準高さの **72%**（伸びた帯全体ではなく `--band-h`）。アイコン幅 **65%**、`aspect-ratio: 1`（高さ％にしない）。
- 優勝: `#ff8600`、min `2.48×1.14rem`、パディング `0.22rem 0.22rem 0.2rem 0.32rem`、M PLUS 1p `0.74rem` / 400、字間 `0.1em`。
- 出走者名: M PLUS 1p 800、`1.02rem`。ウマ娘名: `0.68rem`、`#5a5a5a`。
- 右列 `.facts`: 幅 **38.5%**、左金線 `#b07c18`、上下マージン `0.8rem`。開催名は `-webkit-line-clamp: 2`、`max-height: calc(1.3em * 2)`、`0.84rem` / 800。

単勝・人気・脚質・ウマ番はこの帯に出さない。

## 文言・語り手

- ウマ娘が喋る勝利コメント、公式インタビュー全文、パドック意気込み、優勝者への DM 取材はしない。
- 意気込み（`paddock_comment`）は号外に出さない（紙面にも編集にも出さない）。
- 縦書きの見出しはセレクト（文言だけ。id は出さない）。初期は「見事チャンピオンに」。変更するとカバーの縦書きが変わる。ラウンド・着差からの自動選択はしない。

---

## 管理タブ

ウマ柱に合わせる。管理者のみ。**ラベル「号外」、URL `/admin/gougai`。** ナビはウマ柱の下。

左: スマホ幅（26rem）の紙面プレビュー。右: 編集（誌名・縦書き・右列画像・メインビュー画像・本文）。フォントは IBM Plex に加え **M PLUS 1p**。ヒーロー右に PNG / WebP。出力はプレビュー `.gougai-paper` をクライアントで書き出す（`public/vendor/modern-screenshot.mjs`、`scale: 2`）。印刷はしない。サーバー焼きはしない。D1 に下書きを残さない。ファイル名は `YYYY-MM-DD-{開催名}-号外`（日付は JST）。誌名・縦書き・右列画像の変更は端末のデフォルトとして残す。

メインビュー画像は、この画面を開いている間だけ選択できる。選択すると既定の背景と立ち絵を画像に置き換えるが、縦書き3列と右15%の青枠は維持する。画像はカバー全体の表示枠に合わせて切り抜き、ドラッグと拡大・縮小で調整する。「テンプレートに戻す」で解除する。再読み込みではテンプレートへ戻り、画像・切り抜き位置は保存しない。

1着が無いときは「1着未入力」バナーを出し、紙面はプレースホルダ（スペシャルウィーク／プレビュー太郎。開催名・コースは実データがあれば使う）。

紙面はメンバーの場内・パドック・窓口に出さない。

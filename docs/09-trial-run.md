## やりなおし

投票中、自分の今週の未返還票を全賭式まとめて取消し、残高に戻す。回数・時間は制限しない。ゲートは締切だけ。確認ダイアログ付き。

## 賭式（採用）

単勝・馬連・馬単・3連複・3連単。すべて **1点買い**。複勝・ワイドは必須にしない。

切りの理由: 当選キーが常に1つ。単勝と同じ清算（その賭式の実票プール × (1−D) / 当選の実票）に乗せられる。複勝・ワイドが重いのは Seed ではなく、当たりが複数でプールを分けること。`kind` と買い目を先に置けば後付けできる。

各賭式は別プール。単勝が成立しても 3連単が不成立、はありうる（逆も）。

### 払いの約束（採用: ①）

確定配当は実票だけの山分け。Seed は投票中の参考にだけ混ぜ、締め切り後の計算からは外す。ポイント総量は増刷しない。

### 不成立（採用: 特払い B）

その賭式の当たりの買い目に実票がゼロのとき、その賭式に賭けた人全員へ、控除 D のあと戻す（100 点 → 80 点）。全額返還ではない。投票前・締切後・自分の履歴に同じ案内を出す。

出走取消は別で、そのウマ娘を含む票は **全額** 戻す（実競馬の取消に合わせる）。

### Seed と Real（単勝は採用。連勝 Seed は参考のみ・倍率帯を制約）

- Strength → Seed は、少なくとも単勝に載せる
- 連勝に Seed を載せる場合も **確定には入れない**（①）
- 連勝の票は単勝の Seed にも単勝の Real にも入らない
- w の票量側 TV は賭式ごと（連勝の寄りに単勝の実票を混ぜない）
- 連勝の **w時の下限は単勝より低く** する（時間だけで Seed が薄れ、参考と確定のズレを小さくする）
- 見える連勝の参考を **10〜数十倍** に収めたい、という目標がある。開場直後・実票ゼロだと、均等 Seed でも倍率はだいたい `0.8 × 買い目の数` になる。16頭なら馬連 120 通り → 約 96 倍、馬単 240 → 約 192 倍、3連複 560 → 約 448 倍、3連単 3360 → 約 2700 倍。**式のままで数十倍の上限に収まるのは馬連まで。** 3連単・3連複に Seed を載せて上限を数十倍にするには、表示の打ち止めか、Seed を載せないか、頭数を減らすかが要る

Neko さんの note の 3連単予想は置き換えない。

## 検討メモ（再検討中）連勝への Seed

①のまま参考にだけ Seed を載せる案。見たい倍率帯は **10〜数十倍**。w時下限は連勝の方が低く。

開場直後の上限は買い目数でほぼ決まる（上記 `0.8 × 通り数`）。馬連なら目標帯に近い。3連単は Seed を載せるほど万馬券帯になる。表示キャップ（例: 99 倍で打ち止め）は嘘が増える。

チャット途中までの草案:

- 分け方: 単勝と同じ点の比の延長（馬連は2順を足す）
- S・E は賭式ごと。初期は仮 20000
- 見せ方: 単勝は表、連勝は選んでいる買い目の参考だけ
- w時下限: 単勝は厚め（現行 0.5）、連勝はそれより低く（数値は未決）

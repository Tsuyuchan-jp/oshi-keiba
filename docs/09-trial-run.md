## 流れ

1. `setup`: 16頭を Strength 直置き
2. 投票開始 → `voting`: 入室と投票。やりなおし可
3. 日時または強制締切 → `closed`: 確定配当のみ。着順は出さない
4. 着順保存のあと公開 → `published`: 払戻

## 数字

- G: **3000**
- 単位: 100
- 単勝の S・E: 当面 20000。G に自動連動しない。単勝の作者並びが弱いと感じたら管理画面で S を上げる
- D: 20%（全賭式共通の仮）

## ステータス文言

- `setup`: 出走登録中
- `voting`: 投票中
- `closed`: 投票締切（確定配当）
- `published`: 結果公開

一般画面は `closed` で確定配当だけ。着順は `published` まで出さない。

## 入室

`/login` 1枚・2ボタン。個人パスワードなし。なりすまし耐性は捨てる。

- **初めて入室（登録）**: 未登録なら口座作成＋G。同名ありは拒否
- **登録済み再入室（ログイン）**: 既存なら入室。名前なしは拒否
- 共有仮パス `MEMBER_PASSWORD` は GitHub 経由の無関係な入場を薄く遮るためだけ
- Cookie があれば同じ端末では再入力不要

## やりなおし

投票中、自分の今週の未返還票を全賭式まとめて取消し、残高に戻す。回数・時間は制限しない。ゲートは締切だけ。確認ダイアログ付き。

## 賭式（採用）

単勝・馬連・馬単・3連複・3連単。すべて **1点買い**。複勝・ワイドは必須にしない。

切りの理由: 当選キーが常に1つ。単勝と同じ清算（その賭式の実票プール × (1−D) / 当選の実票）に乗せられる。複勝・ワイドが重いのは Seed ではなく、当たりが複数でプールを分けること。`kind` と買い目を先に置けば後付けできる。

各賭式は別プール。当選キーに実票が無ければ、その賭式だけ不成立・返還。

### Seed と Real（いまの正）

- Strength → Seed は **単勝だけ**
- 連勝に Seed は載せない。投票中の連勝は実票の仮配当（票が無ければ「—」）
- 10人が各賭式に分散しても、単勝の参考は「単勝 Seed ＋ その頭の単勝 Real ＋ w」
- 連勝の票は単勝の Seed にも単勝の Real にも入らない
- w の票量側 TV は **単勝の実票合計**
- 確定配当はどの賭式も、その賭式の Real だけ

倍率の形は JRA のパリミュチュエル。連勝に Seed を足す場合も式は同じで、足りないのは買い目への仮想票の分け方（下記メモ）。

Neko さんの note の 3連単予想は置き換えない。

## 検討メモ（未採用）連勝への Seed

チャットで途中まで話した内容。**試運転の正にはしない。** 続きは通常チャットで決めてから、この節を採用に上げる。

方向性の草案（未ロック）:

- 倍率の式は JRA と同じパリミュチュエル。Seed は買い目への仮想票として足すだけ
- 分け方の候補として「単勝と同じ点の比の延長」（1着のあと残り頭でまた比。馬連は2順を足す、3連複は6順を足す）を見ている
- 床なし、という案が出ている
- S は賭式ごと・初期はどれも 20000、管理画面で触る、という案
- E は仮で S と同じ切り、数字は当日触る、という案
- 見せ方の案: 単勝は表、連勝はフォームで選んでいる買い目の参考だけ
- 試運転に載せるかは未決

決めると実装できるが、未決のまま載せると止まるもの: 頭の Strength から買い目仮想票への規則、連勝参考の見せ方。

## 流れ

1. `setup`: 16頭を Strength 直置き。賭式・S・E・締切をここで揃える
2. 投票開始 → `voting`: 入室と投票。やりなおし可
3. 日時または強制締切 → `closed`: 確定配当のみ。着順は出さない。賭式ごとに成立／特払い予定
4. 着順保存のあと公開 → `published`: 払戻。着順と自分の的中／特払い／取消

## 数字（本戦初期値）

- G: **3000 スペ**（画面上のポイント名称は **スペ** で統一）
- 単位: 100 スペ
- S（単勝 Seed 合計）: **20000**
- E（単勝参考を実票に寄せる目安）: **25000**
- w時下限: **0.5**、w時指数: **1**
- D: **20%**（単勝も連勝も同じ。特払いも 100 スペ → 80 スペ。端数切り捨て）
- G に S・E は自動連動しない

錨の読み: 開場直後の単勝倍率は Strength 比だけで、S の大きさでは変わらない。S は実票が混ざったあとの作者並びの重さ。E は単勝実票がこの額で Seed が消える。20〜25人・全額が多い想定では、単勝に乗るのが全体の3割前後なら約2万、半分なら3万超。E=25000 は単勝全額勢が7〜8人乗ったあたりで参考が実票寄り、という差。連勝に逃げて単勝が薄いときは Seed が残る（場内の単勝が作者並びのまま）。確定は常に実票だけ。

### 投票中に触れるもの

S・E・w時・D・締切日時・タイトルは、管理のレースイベント設定から **投票中でも保存できる**。効くのは主に単勝参考（確定の山分けは実票と D。D を投票中に変えると締切後の払いに効く）。**賭式のオンオフは setup だけ。** 開始後は通常いじらない。触るなら S・E だけ変えて保存する。保存は Undo の1手になる。

## ステータス文言

- `setup`: 出走登録中
- `voting`: 投票中
- `closed`: 投票締切（確定配当）
- `published`: 結果公開

一般画面は `closed` で確定配当だけ。着順は `published` まで出さない。`closed` では賭式ごとに「成立／特払い予定」を出す（当たりの頭は出さない）。

## メンバー画面

入室後と投票は **分ける**。

- **場内（待機）**: 入室直後の場所。出走を待つイメージ。単勝の倍率を出す。投票ボタンは置かない
- **投票ページ**: 馬券を買う専用。所持スペを出す。タイトルで場内へ戻れる

`setup` 中も場内に入れてよい。単勝の倍率（Seed の参考）を見せ、「投票開始までお待ちください」と出す。

`published` は着順、自分の的中／特払い／取消、残高の内訳。公開前の収支は空。

メンバー向けの言葉はすべて **オッズ**。開発・Docs の内部だけ、単勝の投票中を参考オッズ、連勝の実票を仮配当、と分ける。

### 紙面

Tailwind は試運転では入れない。既存の和紙・明朝（`src/lib/ui.ts`）。

- **場内**: 読む。単勝表が本体。投票ボタンは置かない。`voting` のときだけ「馬券を買う」で投票ページへ
- **投票**: 書く。スマホでは **タブ → セレクト → 金額 → 買う** を先に出し、その下にその賭式のオッズを **常時表示**（折りたたみにしない）。タブの下に短い賭式解説
- ヘッダー: 名前・残高（スペ）・フェーズ・使い方。「換金しない」は出さない
- 2段組みの出走表、枠番色、行タップで買う、はやらない（指すのはセレクト）

### 単勝表（場内・投票どちらも）

列は **番号・ウマ娘名・オッズ** だけ。倍率は小数1桁。横スクロールは出さない。Strength と Seed は出さない（管理画面のみ）。

番号は 1 から頭数まで。ゲームの枠番ではない。投票で指し示すためだけの通し番号（名簿の並び）。出走取消すると番号は詰まる。開始後の取消は避けた方がよい。

16頭スマホ: 番号とオッズは狭い列（等幅数字・ゴシック）、名前は明朝1行省略（全文は `title`）。行は詰める。

### 投票ページ

- 賭式は **タブ**。初期は **単勝**（そのオッズ表も最初から出しておく）。無効な賭式のタブは出さない
- タブは1行横スクロール、アクティブは下線。丸チップにしない。スワイプで賭式は変えない
- 1着・2着・3着はセレクト。**同じ頭は二度選べない**（送ってからエラーにしない）
- 馬連・3連複は順不同。内部で番号をソートする
- 連勝のオッズは、**実票がある組み合わせの短い一覧**。空は **「—」**（最初の1票のあと、そのタブを開き直すと表が出る）
- 金額: 単位 100 スペ。ボタンは +100 / +500 / 残り全部
- 買う前に確認ダイアログ（賭式・買い目・金額）
- 自分の票は賭式・組み合わせ・額。同じ組み合わせは一覧でまとめる。公開前に他人の票は出さない
- やりなおしはページ最下部の文字リンク（買うボタンの隣に置かない）

やりなおし確認: 「全ての馬券がリセットされますがよろしいですか？」

換金しない、は出さない。

### ライブ更新

投票中だけ。間隔 **5秒**。ページが裏なら止める。`closed` / `published` では止める。

- 差が 0.1 倍以上の行だけ黄パルス。全行点滅はしない
- 連勝は「—」から数字になった行を1回パルス。票が消えた行は静かに外す
- セレクトと金額は保持し、表だけ差し替える
- 「更新しました」トーストは出さない。ヘッダーに小さな「ライブ」
- 自分の投票直後は、その行を一度強く光らせてよい
- 締切後もフォームが残ることがある。送信は拒否される。ライブ表示が消えたら場内へ戻す

### 使い方モーダル

画面では「使い方」。Seed・Strength・控除の記号は出さない。特払い段落は必須。本文は実装済みのものを本戦とする。

締切後（賭式ごと。例は 3連単）:

「3連単は当たりの組み合わせに投票がなかったため、特払いです。この賭式に使ったスペの8割が戻ります。」

自分の履歴: 「特払い（8割戻し）」

## 入室

`/login` 1枚・2ボタン。個人パスワードなし。なりすまし耐性は捨てる。

- **初めて入室（登録）**: 未登録なら口座作成＋G。同名ありは拒否
- **登録済み再入室（ログイン）**: 既存なら入室。名前なしは拒否
- 表示名: 空白だけは不可。極端に長くなければ通す（絵文字可）
- 共有仮パスは **`loh`**。閉じた経路で渡す。忘れたときの画面案内は置かない
- Cookie があれば同じ端末では再入力不要
- 投票期間外の入室は **可**

## やりなおし

投票中、自分の今週の未返還票を全賭式まとめて取消し、残高に戻す。回数・時間は制限しない。ゲートは締切だけ。確認は「全ての馬券がリセットされますがよろしいですか？」

## 賭式

単勝・馬連・馬単・3連複・3連単。すべて **1点買い**。複勝・ワイドは必須にしない。

管理のレースイベント設定で、**投票開始前（setup）だけ** 使う賭式を選ぶ。単勝は外せない。ほか4つはチェック（初期は全部オン）。開始後は変えない。

切りの理由: 当選キーが常に1つ。単勝と同じ清算（その賭式の実票プール × (1−D) / 当選の実票）に乗せられる。複勝・ワイドが重いのは Seed ではなく、当たりが複数でプールを分けること。`kind` と買い目を先に置けば後付けできる。

各賭式は別プール。単勝が成立しても 3連単が不成立、はありうる（逆も）。

### 払いの約束（①）

確定配当は実票だけの山分け。Seed は投票中の参考にだけ混ぜ、締め切り後の計算からは外す。ポイント総量は増刷しない。

### 不成立（特払い B）

その賭式の当たりの組み合わせに実票がゼロのとき、その賭式に賭けた人全員へ、控除 D のあと戻す（100 スペ → 80 スペ、端数切り捨て）。全額返還ではない。案内は使い方モーダル、締切後の賭式ごと、自分の履歴。

出走取消は別で、そのウマ娘を含む票（連勝のその1点を含む）は **全額** 戻す。

### Seed と Real

- Strength → Seed は **単勝だけ**。投票中の単勝参考は Seed × w ＋ 単勝 Real
- 連勝の投票中表示は **実票だけ**（票が無ければ「—」）。確定も実票だけ（①）
- 連勝の票は単勝の Seed にも単勝の Real にも入らない
- w の票量側 TV は、単勝参考については **単勝の実票合計**

Neko さんの note の 3連単予想は置き換えない。

## 管理

- レースイベント設定はアコーディオン。setup 中は開く。投票開始後は「通常いじりません」
- 週次モニター: いまのフェーズと次に押すもの
- 自己登録済みの名前・残高（読み取り。事前名簿は作らない）。メンバー削除あり（投票中はオッズが変わる。開始後は使わない）
- 全投票一覧（誰が・どの賭式・どの組み合わせ・いくら）。並びは新しい順と名前順。確定配当と収支は結果公開後だけ（公開前の収支は空）
- 代行投票は出さない
- Strength と Seed は管理画面のみ
- setup 中の名前・Strength 修正。一括は `名前、点数` を改行で繰り返す
- 直前の管理者操作を1手戻せる（二段確認＋パス）。メンバー投票のあとに「投票開始」を戻すと票が消える
- デモ初期化: メンバー口座（表示名）は残す。残高は全員 3000。誤タップ防止で確認に加え管理者パス
- `/demo` をナビから外す。架空メンバーを作らない
- `/logout` は `/` へ
- 管理者パスは当面 `demo-admin`。メンバー共有パスは `loh`

## 当日オペ（アプリ）

1. 本番でデモ初期化（先。確認と管理者パス）。旧手土産の出走が残っていたら必須
2. タイトル・締切日時（JST）を **保存**。G=3000、S=20000、E=25000、w時下限 0.5、D=20%、賭式を確認
3. 受領済み Strength を 16頭直置き（一括貼り付け可。名前は完全一致）
4. 投票開始（日時は保存済みであること。過去日時だと開始直後に自動締切）
5. URL ＋ 共有パス `loh` を閉じた経路で渡す
6. ゲーム内で着順が見える前に締切（日時または強制）
7. note に合わせて着順入力 → 結果公開して払戻

取消は出走取消。飛び入りはアプリに足さない。投票開始後はデモ初期化・Undo・メンバー削除を押さない。締切日時は開始ボタンとは別フォームなので、入れてから保存して開始する。

## 後付け用メモ: 連勝への Seed

本戦では出さない。参考にだけ足すなら確定は触らない。案が固まってからでよい。

制約の控え: 開場直後・実票ゼロのパリミュチュエルはだいたい `0.8 × 買い目の数`。16頭 3連単は約 2700 倍。S や全体に同じ P を掛けてもこの桁は消えない。数十倍帯にするなら差をなだらかにするか表示上限か、箱を減らす。w時下限を連勝だけ下げるのは、寄せ用。

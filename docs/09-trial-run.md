## 流れ

1. `setup`: 16頭を Strength 直置き
2. 投票開始 → `voting`: 入室と投票。やりなおし可
3. 日時または強制締切 → `closed`: 確定配当のみ。着順は出さない
4. 着順保存のあと公開 → `published`: 払戻

## 数字

- G: **3000**
- 単位: 100
- 単勝の S・E: 当面 20000。G に自動連動しない。単勝の作者並びが弱いと感じたら管理画面で S を上げる
- D: 20%（全賭式共通の仮。特払いも同じ 20% を残して戻す → 100 点あたり 80 点）

## ステータス文言

- `setup`: 出走登録中
- `voting`: 投票中
- `closed`: 投票締切（確定配当）
- `published`: 結果公開

一般画面は `closed` で確定配当だけ。着順は `published` まで出さない。`closed` では賭式ごとに「成立／特払い予定」を出す（当たりの頭は出さない）。変更の余地あり。

## メンバー画面（ここまで採用）

入室後と投票は **分ける**。

- **場内（待機）**: 入室直後の場所。出走を待つイメージ。単勝の倍率を出す。投票ボタンは置かない
- **投票ページ**: 馬券を買う専用

`setup` 中も場内に入れてよい。単勝の倍率（Seed の参考）を見せ、「投票開始までお待ちください」と出す。

`published` は着順、自分の的中／特払い／取消、残高の内訳。

メンバー向けの言葉はすべて **オッズ**。開発・Docs の内部だけ、単勝の投票中を参考オッズ、連勝の実票を仮配当、と分ける。

やりなおし確認: 「全ての馬券がリセットされますがよろしいですか？」

換金しない、は出さない。少人数で 3連単が特払いになりやすいことは **使い方モーダル** に仮置き。

### 特払い文面（採用）

使い方モーダル:

「人数が少ないと、3連単などは当たりの組み合わせに投票が1件もないことがあります。そのときは『特払い』になり、その賭式に使ったポイントの8割が戻ります。」

締切後（賭式ごと。例は 3連単）:

「3連単は当たりの組み合わせに投票がなかったため、特払いです。この賭式に使ったポイントの8割が戻ります。」

自分の履歴:

「特払い（8割戻し）」

## 入室

`/login` 1枚・2ボタン。個人パスワードなし。なりすまし耐性は捨てる。

- **初めて入室（登録）**: 未登録なら口座作成＋G。同名ありは拒否
- **登録済み再入室（ログイン）**: 既存なら入室。名前なしは拒否
- 共有仮パス `MEMBER_PASSWORD` は GitHub 経由の無関係な入場を薄く遮るためだけ
- Cookie があれば同じ端末では再入力不要

## やりなおし

投票中、自分の今週の未返還票を全賭式まとめて取消し、残高に戻す。回数・時間は制限しない。ゲートは締切だけ。確認は「全ての馬券がリセットされますがよろしいですか？」

## 賭式（採用）

単勝・馬連・馬単・3連複・3連単。すべて **1点買い**。複勝・ワイドは必須にしない。

切りの理由: 当選キーが常に1つ。単勝と同じ清算（その賭式の実票プール × (1−D) / 当選の実票）に乗せられる。複勝・ワイドが重いのは Seed ではなく、当たりが複数でプールを分けること。`kind` と買い目を先に置けば後付けできる。

各賭式は別プール。単勝が成立しても 3連単が不成立、はありうる（逆も）。

### 払いの約束（採用: ①）

確定配当は実票だけの山分け。Seed は投票中の参考にだけ混ぜ、締め切り後の計算からは外す。ポイント総量は増刷しない。

### 不成立（採用: 特払い B）

その賭式の当たりの買い目に実票がゼロのとき、その賭式に賭けた人全員へ、控除 D のあと戻す（100 点 → 80 点）。全額返還ではない。案内は使い方モーダル、締切後の賭式ごと、自分の履歴。文面は「メンバー画面」節。

出走取消は別で、そのウマ娘を含む票は **全額** 戻す（実競馬の取消に合わせる）。

### Seed と Real（MVP 採用）

- Strength → Seed は **単勝だけ**。投票中の単勝参考は Seed × w ＋ 単勝 Real
- 連勝の投票中表示は **実票だけ**（票が無ければ「—」）。確定も実票だけ（①）
- 連勝の票は単勝の Seed にも単勝の Real にも入らない
- w の票量側 TV は、単勝参考については **単勝の実票合計**
- 時間があれば、連勝の参考にだけ Seed を足してよい。確定には載せない。入れ物（賭式・買い目・実票）は先に置く

Neko さんの note の 3連単予想は置き換えない。

## 後付け用メモ: 連勝への Seed

MVP では出さない。参考にだけ足すなら確定は触らない。案が固まってからでよい。

制約の控え: 開場直後・実票ゼロのパリミュチュエルはだいたい `0.8 × 買い目の数`。16頭 3連単は約 2700 倍。S や全体に同じ P を掛けてもこの桁は消えない。数十倍帯にするなら差をなだらかにするか表示上限か、箱を減らす。w時下限を連勝だけ下げるのは、寄せ用。
